# تصميم الصفحات: اختصارات الشارات + «المهلة» + «القوة الجبرية»

## Global Styles (Desktop-first)
- التخطيط العام: حاوية مركزية بعرض أقصى 1200px، وهوامش داخلية 24px.
- الألوان:
  - الخلفية: #0B1220 (داكنة) أو #F7F8FA (فاتحة) حسب ثيم التطبيق الحالي.
  - النص الأساسي: #111827 / على الداكن #E5E7EB.
  - اللون الأساسي (Primary): #2563EB.
  - التحذير: #F59E0B، الخطر: #EF4444، النجاح: #10B981.
- الطباعة:
  - العناوين: 18–24px، وزن 600.
  - النص: 14–16px.
- الأزرار:
  - Primary: خلفية Primary + نص أبيض.
  - Secondary: إطار 1px + خلفية شفافة.
  - Hover: زيادة إضاءة/تعتيق 6–10% وانتقال 120ms.
- الروابط: Primary مع underline عند hover.
- عناصر الشارة (Badge chip): كبسولة (Pill) بارتفاع 24–28px، لون حسب إعداد الاختصار.

## 1) صفحة: لوحة المواعيد والسجل (Route: /)

### Layout
- نظام: CSS Grid (عمودان) على سطح المكتب.
  - العمود الأيسر (65%): قائمة المواعيد.
  - العمود الأيمن (35%): السجل + الحاويات الثانوية (مخفية افتراضياً).
- على الشاشات الصغيرة: عمود واحد (Stacked) مع نقل السجل أسفل القائمة.

### Meta Information
- Title: لوحة المواعيد والسجل
- Description: إدارة المواعيد وتطبيق الشارات ومراجعة السجل.
- Open Graph: title/description مطابقان، type: website.

### Page Structure
1. شريط علوي (Top Bar)
2. شريط اختصارات الشارات
3. منطقة المحتوى (Grid)
   - قائمة المواعيد
   - لوحة السجل
   - (حاويات ثانوية مخفية افتراضياً)

### Sections & Components
**A) Top Bar**
- يسار: اسم الصفحة.
- يمين: زر الانتقال إلى إعدادات اختصارات الشارات.

**B) شريط اختصارات الشارات (Sticky تحت الشريط العلوي)**
- عناصر أفقية (chips/buttons) لكل اختصار مُمكّن.
- كل عنصر يعرض: لون الشارة + label.
- Interaction:
  - عند اختيار موعد من القائمة، يصبح تطبيق الشارة موجهاً لهذا الموعد.
  - عند الضغط على اختصار شارة: تحديث شارة الموعد + Toast نجاح + إضافة حدث للسجل.
  - عند عدم تحديد موعد: تعطيل الأزرار أو إظهار رسالة "اختر موعداً أولاً".

**C) قائمة المواعيد (Appointments List)**
- قائمة بطاقات (Cards) بارتفاع ثابت تقريباً.
- كل بطاقة تعرض:
  - العنوان + وقت/تاريخ.
  - شارة الحالة الحالية (badge_key) إن وجدت.
  - مؤشرات صغيرة إن كانت «المهلة» أو «القوة الجبرية» مفعّلة/معبأة.
- Interaction:
  - النقر يحدد الموعد.
  - زر "فتح التفاصيل" ينقلك إلى /items/:id.

**D) لوحة السجل (History Panel)**
- قائمة زمنية (Timeline) بعناصر صغيرة.
- كل حدث يعرض: نوع الحدث (تغيير شارة/تعديل مهلة/تعديل قوة جبرية) + الوقت + قيمة قبل/بعد عند توفرها.

**E) زر اختصار الحاويات (Containers Toggle Button)**
- زر واضح (Secondary) بعنوان: "إظهار الأدوات" / "إخفاء الأدوات".
- افتراضياً: الحاويات الثانوية مخفية.
- عند التفعيل: يظهر قسم جانبي إضافي (مثل "إجراءات سريعة" أو "فلترة") بدون أن يظهر تلقائياً.

**F) الحاويات الثانوية (Hidden Containers)**
- لا تظهر إلا بعد الضغط على زر الاختصار.
- أمثلة محتوى ضروري فقط:
  - فلترة المواعيد (اليوم/الأسبوع).
  - فرز (الأحدث/الأقدم).

## 2) صفحة: تفاصيل الموعد/السجل (Route: /items/:id)

### Layout
- نظام: Flexbox عمودي مع بطاقات (Cards) منفصلة.
- عمود رئيسي بعرض 760–900px في المنتصف.

### Meta Information
- Title: تفاصيل الموعد
- Description: عرض وتعديل خصائص الموعد وتسجيلها في السجل.
- Open Graph: title/description مطابقان.

### Page Structure
1. رأس الصفحة: رجوع + عنوان الموعد
2. بطاقة معلومات أساسية
3. بطاقة مسار «المهلة»
4. بطاقة مسار «القوة الجبرية»
5. بطاقة سجل هذا الموعد
6. (اختياري ضمن نفس الصفحة) شريط اختصارات الشارات

### Sections & Components
**A) Header**
- زر رجوع إلى لوحة المواعيد.
- عنوان: اسم/معرف الموعد.

**B) بطاقة المعلومات الأساسية**
- حقول قراءة فقط غالباً: العنوان، التاريخ/الوقت، الشارة الحالية.
- زر "تطبيق شارة" يفتح منبثق بسيط أو يعرض الشريط.

**C) بطاقة مسار «المهلة»**
- عنصر إدخال واحد بحسب النموذج:
  - حقل نصي/قائمة (إن كانت قيماً محددة) أو مدة.
- زر حفظ.
- حالة التحميل/النجاح/الخطأ واضحة.
- عند الحفظ: تحديث appointments.timeout_value + إضافة history_event.

**D) بطاقة مسار «القوة الجبرية»**
- مماثلة لبطاقة المهلة.
- عند الحفظ: تحديث appointments.forced_power_value + إضافة history_event.

**E) سجل الموعد**
- Timeline مصغر للأحداث المرتبطة بـ appointment_id.

## 3) صفحة: إعدادات اختصارات الشارات (Route: /settings/badges)

### Layout
- نظام: CSS Grid
  - يسار: قائمة الاختصارات الحالية (قابلة للسحب لإعادة الترتيب إن كان ذلك متاحاً لاحقاً).
  - يمين: نموذج إنشاء/تعديل.
- على الشاشات الصغيرة: Stack.

### Meta Information
- Title: إعدادات اختصارات الشارات
- Description: إدارة اختصارات الشارات وترتيبها وتفعيلها.
- Open Graph: title/description مطابقان.

### Page Structure
1. رأس الصفحة: رجوع + عنوان
2. جدول/قائمة الاختصارات
3. نموذج إضافة/تعديل اختصار

### Sections & Components
**A) قائمة الاختصارات**
- أعمدة: اللون، الاسم (label)، المفتاح (key)، الحالة (مفعّل/معطّل)، الترتيب.
- إجراءات لكل عنصر: تعديل، تعطيل/تفعيل، حذف.

**B) نموذج الاختصار**
- حقول:
  - key (فريد)
  - label
  - color (اختيار لون)
  - is_enabled
- تحقق:
  - منع key مكرر.
  - label غير فارغ.

### Responsive behavior
- Desktop-first مع نقاط توقف:
  - >=1024px: تخطيط عمودين.
  - 640–1023px: عمود واحد مع ترتيب أقسام.
  - <640px: أزرار بعرض كامل، تقليل الحشو الداخلي إلى 16px.

### Interaction states
- Loading skeleton لقائمة المواعيد/السجل.
- Toasts: نجاح الحفظ/فشل الحفظ.
- Disabled states: تعطيل شريط الاختصارات عند عدم اختيار موعد.
