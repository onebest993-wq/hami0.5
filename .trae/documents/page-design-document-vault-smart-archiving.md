# تصميم الصفحات — خزينة المستندات (أرشفة ذكية)
مبدأ أساسي: **الحفاظ على التصميم والألوان الحالية** عبر إعادة استخدام نفس Design Tokens/Components الموجودة (ألوان، خطوط، أزرار، بطاقات، حقول إدخال، تباينات، ظلال).

## 1) إعدادات عامة (Global)
### Layout (Desktop-first)
- تخطيط أساسي: **Grid + Flex**.
- سطح المكتب: شريط جانبي للمجلدات (يسار) + مساحة محتوى (يمين).
- نقاط التوقف: 
  - ≥ 1024px: Sidebar ثابت (قابل للطي) + Content.
  - < 1024px: Sidebar يتحول إلى Drawer.

### Meta Information (مشتركة)
- Title template: `خزينة المستندات — {اسم الصفحة/المجلد}`
- Description: `أرشفة ذكية للمستندات: مجلدات، فرز، فلترة، رفع، معاينة.`
- Open Graph: استخدام نفس الإعدادات الحالية للتطبيق (نفس صورة OG إن وجدت).

### Global Styles
- الألوان: إعادة استخدام متغيرات/توكنز النظام الحالي (مثال توضيحي: `--color-primary`, `--color-surface`, `--color-text`) بدون إدخال لوحة جديدة.
- الطباعة: نفس الخط الحالي؛ أحجام مقترحة (تتبع scale الحالي): عنوان صفحة، عنوان قسم، نص ثانوي.
- الأزرار والروابط: نفس حالات hover/active/disabled الحالية.
- الحالات: نجاح/خطأ/تحميل باستخدام نفس مكونات الـToast/Alert/Spinner الحالية.

## 2) صفحة «خزينة المستندات» (/documents)
### Meta
- Title: `خزينة المستندات`
- Description: `استعراض المستندات داخل المجلدات مع فرز/فلترة ورفع/كاميرا.`

### Page Structure
- Header علوي داخل المحتوى + تخطيط ثنائي الأعمدة:
  - **Sidebar (Folders)**
  - **Main Content (Documents List)**

### Sections & Components
1. **شريط علوي (Top Bar)**
   - Breadcrumb: (خزينة المستندات / اسم المجلد).
   - يمين الشريط: أزرار أساسية
     - زر **رفع ملف** (يفتح File Picker).
     - زر **كاميرا** (يفتح Modal للالتقاط).

2. **Sidebar: المجلدات**
   - عنوان: «المجلدات» + زر صغير «إدارة» ينقلك إلى /folders.
   - قائمة/شجرة مجلدات:
     - عنصر مجلد: اسم + عدّاد (اختياري إن كان متوفرًا بسهولة).
     - حالة اختيار واضحة بنفس نمط الـActive الحالي.
   - سلوك:
     - قابل للطي على سطح المكتب.
     - Drawer على الشاشات الأصغر.

3. **منطقة التحكم (Controls Row)**
   - فلترة النوع: Tabs/Dropdown (PDF، صور، الكل).
   - فرز: Dropdown (الأحدث، الأقدم، الاسم).
   - (اختياري ضمن نفس الصف): مؤشر عدد النتائج في المجلد.

4. **قائمة المستندات (Documents List/Grid)**
   - عرض افتراضي: جدول/قائمة (List) لملاءمة الأرشفة.
   - صف المستند يحتوي:
     - أيقونة نوع الملف (PDF/صورة).
     - اسم المستند.
     - تاريخ الإضافة.
     - زر «⋯» لإجراءات المستند.
   - حالات:
     - Empty state عند عدم وجود مستندات داخل المجلد.
     - Loading skeleton أثناء التحميل.

5. **إجراءات المستند (Action Menu) لكل عنصر**
   - عناصر القائمة:
     - «معاينة» (ينقلك إلى /documents/:id).
     - «إعادة تسمية» (Modal مع حقل نص + حفظ).
     - «نقل إلى مجلد» (Modal اختيار مجلد وجهة).

6. **Modal: الالتقاط بالكاميرا**
   - معاينة كاميرا مباشرة + زر التقاط.
   - بعد الالتقاط:
     - معاينة الصورة.
     - زر «تحويل إلى PDF وحفظ».
     - إظهار Progress أثناء التحويل/الرفع.
   - رسائل أخطاء واضحة عند رفض إذن الكاميرا.

## 3) صفحة «معاينة مستند» (/documents/:id)
### Meta
- Title: `معاينة — {اسم المستند}`
- Description: `قراءة المستند وتنفيذ إجراءات أساسية.`

### Page Structure
- Header علوي + منطقة عرض رئيسية + لوحة معلومات جانبية (على سطح المكتب).
  - على الشاشات الأصغر: اللوحة الجانبية تتحول إلى Accordion أسفل العارض.

### Sections & Components
1. **Header**
   - زر رجوع إلى /documents.
   - عنوان: اسم المستند.
   - إجراءات سريعة: «إعادة تسمية» + «نقل».

2. **عارض المستند (Viewer)**
   - إذا كان PDF: عارض PDF مع (تكبير/تصغير، انتقال صفحات).
   - إذا كان صورة: عارض صورة مع (تكبير/تصغير) أو عرض ملائم للحاوية.
   - الحفاظ على ألوان الخلفية/الإطارات بنفس أسلوب الـCard الحالي.

3. **لوحة المعلومات (Info Panel)**
   - حقول: المجلد الحالي، تاريخ الإضافة، نوع الملف.
   - زر «نقل» يفتح نفس Modal اختيار المجلد.
   - زر «إعادة تسمية» يفتح Modal إعادة التسمية.

---

## 4) صفحة «إدارة المجلدات» (/folders)
### Meta
- Title: `إدارة المجلدات`
- Description: `إنشاء وتنظيم المجلدات لدعم الأرشفة.`

### Page Structure
- تخطيط صفحة واحدة مع قسمين:
  - قائمة المجلدات (يسار) + لوحة إجراءات/تفاصيل (يمين).

### Sections & Components
1. **قائمة المجلدات**
   - زر «مجلد جديد».
   - قائمة مجلدات قابلة للتمرير.
   - اختيار مجلد لعرض تفاصيله.

2. **لوحة الإجراءات**
   - إعادة تسمية المجلد (حقل + حفظ).
   - حذف المجلد:
     - إذا كان غير فارغ: عرض رسالة تمنع الحذف أو تطلب نقل المحتوى أولاً (حسب منطق المنتج).

3. **اختيار وجهة النقل (يُستخدم أيضًا كـModal من الصفحات الأخرى)**
   - قائمة/بحث داخل المجلدات.
   - زر تأكيد النقل + إلغاء.

---

## 5) ملاحظات تفاعلية (Interaction)
- جميع العمليات (رفع/تحويل/نقل/إعادة تسمية) تُظهر حالات: Loading → Success/Error باستخدام نفس نظام الإشعارات الحالي.
- الحفاظ على نفس التباينات (Contrast) والألوان وعدم إدخال ألوان جديدة؛ أي عنصر جديد يجب أن يعتمد على نفس الـTokens الحالية.
