## الصفحة: سجل حجوزات العقار (بعد موافقة المنفّذ)

### Layout
- **نمط:** 3 أعمدة (Desktop):
  1) عمود يسار: قائمة المدينين.
  2) عمود وسط: سجل البطاقات (Cards).
  3) عمود يمين: لوحة تفاصيل/سجل عمليات للبطاقة المحددة (اختياري داخل نفس الصفحة).
- **التنفيذ:** CSS Grid للهيكل العام + Flex داخل البطاقات.
- **Responsive:**
  - ≥1200px: 280px / 1fr / 360px.
  - 768–1199px: قائمتان (مدينين + بطاقات) مع إخفاء لوحة اليمين وتفتح كـ Drawer.
  - <768px: تبويب علوي (مدينين/بطاقات) والمودالات fullscreen.

### Page Structure
1) شريط علوي ثابت (Header)
2) منطقة المحتوى الرئيسية (3 أعمدة)
3) مودالات/حوارات تأكيد (Property Modal + Confirm Actions)

### Sections & Components

#### 1) Header (Top Bar)
- **العناصر:**
  - عنوان الصفحة.
  - حقل بحث سريع (اسم المدين/مرجع العقار).
  - مرشح حالة (الكل/موافقة منفّذ/مقفلة/متراجع عنها).
- **التفاعلات:** تحديث فوري للقوائم، مع مؤشر تحميل صغير.

#### 2) قائمة المدينين (Left Column)
- **Debtor List Item:**
  - اسم المدين.
  - **شارة تحت اسم المدين** (Badge Under Name):
    - حالات مختصرة: "موافَق عليه" (Success) / "قيد الإجراء" (Warning) / "مقفّل" (Neutral) / "متراجع" (Danger).
  - عدّاد عدد البطاقات إن توفر.
- **Interaction:** اختيار عنصر يفلتر البطاقات في العمود الأوسط.

#### 3) سجل الحجوزات ببطاقات (Center Column)
- **Card Anatomy:**
  - رأس البطاقة: مرجع العقار + حالة (مزايدة/بيع) + وسم حالة دورة الحياة.
  - جسم البطاقة: ملخص العقار (سطرين) + المبالغ (الأساس/الخصم/النهائي).
  - ذيل البطاقة: أزرار إجراءات.
- **حالات مزايدة/بيع:**
  - Toggle/Segmented control: "مزايدة" / "بيع".
  - عند "مزايدة": زر "إضافة عرض" (إن كان مسموحاً) + عرض أعلى عرض بشكل موجز.
- **منطق الخصم (UI):**
  - اختيار نوع الخصم: نسبة % أو مبلغ.
  - إدخال قيمة الخصم.
  - عرض حساب مباشر: النهائي = الأساس - الخصم.
- **القفل:**
  - عند is_locked=true: تعطيل (Toggle المزاد/البيع + إدخال الخصم) وإبقاء "عرض التفاصيل" و"سجل العمليات" فقط.

#### 4) لوحة تفاصيل/سجل عمليات (Right Column) — داخل نفس الصفحة
- **الغرض:** توضيح كل تغيّر على البطاقة.
- **العناصر:**
  - معلومات البطاقة المختارة.
  - Timeline بسيط للأحداث (event_type + وقت + فاعل).
  - زر "فتح القفل" (للمنفّذ فقط) يظهر فقط إذا كانت البطاقة مقفلة.

#### 5) مودال بيانات العقار (Property Data Modal)
- **فتح:** من زر "بيانات العقار" داخل البطاقة.
- **المحتوى:**
  - مرجع العقار/الوصف.
  - موقع مختصر.
  - ملخص الملكية والقيود (إن توفر).
  - زر "إغلاق" واضح.
- **تصميم:** Modal بعرض 720px على Desktop، وfullscreen على Mobile.

#### 6) حوار تأكيد "فك/تراجع" + قفل البطاقة
- **فتح:** زر "فك/تراجع" داخل البطاقة.
- **المحتوى:**
  - تحذير واضح (Danger) بأن العملية ستُسجّل.
  - اختيار سبب مختصر (نصي اختياري إذا كان مطلوباً ضمن البيانات المتاحة).
  - أزرار: "تأكيد" (Destructive) و"إلغاء".
- **بعد التأكيد:**
  - تحديث الحالة.
  - تطبيق قفل/تجميد حسب السياسة.
  - إضافة حدث في سجل العمليات.

### Interaction States
- Loading: Skeleton للبطاقات والقائمة.
- Empty: رسالة "لا توجد حجوزات" مع إرشاد لتغيير المرشحات.
- Error: Toast ثابت أعلى اليمين + إعادة المحاولة.
