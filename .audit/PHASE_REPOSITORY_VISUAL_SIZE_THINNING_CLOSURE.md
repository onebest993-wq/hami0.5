# إغلاق قسم — المستودع: تنحيف الحجم والتصميم

**التاريخ:** ٣٠ آب ٢٠٢٦  
**النطاق:** بلاطة `dockRepository` / المستودع الذكي (الخلاصة، الكروم، المسودة، ألواح المخزن، مسجّل الصوت عند الإضافة).  
**الإذن:** بصري صريح من المالك — تكثيف وخفّة احترافية، مع الإبقاء على أهداف لمس 44px.

لا تغيير على عقد الشبكة/WIFE/ختم KV من المرحلة السابقة.

---

## ما أُنجز

### تصميم (كثافة بلا زخرفة)

- ثيم مضغوط مسبقاً ومُثبَّت باختبار: `rounded-xl`، حشو `px-3 py-1.5` / `p-2.5`، صور الخلاصة **11rem**، ظل الفلاتر `0 2px 12px`.
- بطاقات القائمة/المحتوى: فجوات أصغر، مصغّرات `4.25rem` / `3.75rem` / `w-20`.
- معرض الغرف وقوائم النقل/الربط: `rounded-xl` بلا `2xl`.
- شريط البحث وألواح الرفع/الماسح: نفس لغة الكحلي المسطّح.
- `vaultDustyRoseTheme.ts`: حُذف الترافرتين/التدرج النحاسي والثوابت الميتة (`VAULT_CARD` / `VAULT_PANEL` / …). بقي المستخدم فقط.
- مسجّل الصوت (مسار «+ إضافة»): بلا ظل 80px ولا `rounded-[22px]` ولا أزرار `h-14` — 44px و`rounded-xl`.

### حجم JS (أول فتح للخلاصة)

| قبل هذه الشريحة (مسار الخلاصة) | بعد |
|-------------------------------|-----|
| حفظ الملف عبر استيراد ساكن لـ `vaultUploadService` من الهوكات | `saveFileToVault` **ديناميكي** عند الحفظ فقط |
| الماسح/الصوت/المحرر تُسخَّن مع Host | Host يسخّن blob store + حوارات فقط |
| المسودة وألواح المخزن في مقطع الخلاصة | `lazy()` للمسودة والألواح؛ التركيب عند الحاجة؛ تسخين عند فتح قائمة «إضافة» |
| عرض الوثيقة مربوط بملف الحفظ | `vaultDocResolve` + `vaultFileGuards` منفصلان |
