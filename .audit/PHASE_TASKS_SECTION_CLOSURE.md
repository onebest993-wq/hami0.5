# قسم المهام — إغلاق صادق

**التاريخ:** ٣٠ آب ٢٠٢٦  
**النطاق:** أجندة المهام + ستارة الميدان + QuantumTasks + مساعدة المهام. بلا معاملات/تنفيذ.

هذه الدفعة تُغلق القسم بما هو قابل للإكمال الآن. ليست شهادة «مثالي» ولا جاهزية أصل.

## ما أُنجز ويستحق البقاء

| بند | الحكم |
|-----|--------|
| ترحيل الأجندة عند العودة (تبويب + Capacitor) | علة حقيقية؛ `useVisibilityAwareInterval` ينبض حتى لو المؤقّت لم يُفرَّغ |
| تفريغ القرص عند الخلفية | `useQuantumTasksBackgroundFlush` — pagehide، إخفاء بـ 900ms، و`hami-native-app-state` فوراً |
| توقيع الترحيل يشمل `parsedDate`/`reminderAt` | يمنع تخطّي ترقية المؤجّل عند منتصف الليل |
| توقيع بطاقة موحّد (`legalTaskUiSignature`) | ستارة وأجندة لا تتجمّد بعد ربط ملف أو تغيير تاريخ |
| فك التثبيت عند التحويل إلى حتمي | الزر/الستارة لا يكذبان |
| موجز التنبيه مرة لكل معرّف | `consumeFocusTaskBrief` |
| قشرة الفتح الفوري | ثوابت مشتركة بين React و`innerHTML` — ما زال مساران عن عمد |
| حوار حتمي للستارة مؤجَّل + تسخين بعد hydrate | خارج مقطع الفتح الأول |
| `inert` أثناء حوار الستارة الحتمي | الطبقة خلف الحوار لا تُنقر |
| منطق حوارات الأجندة في `useTasksManagerDialogActions` | معالجات ثابتة؛ overlays تركيب فقط — بلا `useCallback([ctrl])` |
| إزالة `fatalPulse` وتقسيم صف الحالة | كود ميت + ملف أوضح بلا تغيير بصري مقصود |

## اختبارات هذه الدفعة

Vitest لشرائح المهام + الترحيل + التوقيع + الستارة + العزل + كثافة/نظافة/أمان/موبايل + صدق العلل + تفريغ الخلفية + ثبات المزود + **سلوك حوارات التذكير/التعديل**: **١١٦ ناجحة**.

لم يُشغَّل Playwright (الإعداد يفضّل `dist` إن وُجد؛ مسار الـ E2E طويل ويعتمد على تمهيد جلسة). لم يُشغَّل `tsc` كامل ولا جهاز ولا متصفح تفاعلي. الخادم `npm run dev` كان يعمل؛ التغيير الأخير منطقي لا إعادة رسم.

## التقييم (واقعي)

| البُعد | درجة | لماذا ليست أعلى |
|--------|------|------------------|
| أداء | 7.5 | إصلاح ترحيل/تفريغ من الكود؛ بلا قياس جهاز أو TTFI |
| نظافة | 8 | تقسيم حقيقي؛ overlays ما زال سلك خصائص طويلة؛ حوارا الحتمي نسختان بصريتان عن عمد |
| أمان | 8 | العقد (AES / عزل شبكة / لا مزامنة تقويم لعناوين الميدان) لم يُمسّ |
| جودة | 8 | هوك حوارات بسلوك مختبَر؛ كثير من اختبارات «الصدق» ما زالت قراءة مصدر |
| موبايل | 7.5 | 44px / inset / reduceMotion / رجوع أصل في المصدر؛ Capacitor غير مُجَرَّب على جهاز |
| صدق | 9 | الحدود أدناه ليست تجميل |

**جاهز للانتقال:** نعم — بمعنى: لا عمل جوهري متبقٍ داخل القسم يمكن إكماله الآن دون إذن بصري أو كسر عقد أو جهاز حقيقي.

## حدود معلنة — ليست عللاً مؤجّلة داخل القسم

- **شارة المصروف** تُعرض إن وُجدت في التخزين. لا واجهة إضافة. إعادتها أو إخفاؤها يحتاج إذناً صريحاً (بصري/منتج).
- **تثبيت ستارة واحد، التثبيت عبر الأيام، `status: pending` مع `completedAt`، النسخة الحية تربح عند الدمج:** عقود اختبار قائمة.
- **قشرة الفتح:** React + `innerHTML` بنفس الثوابت. مسار الطلاء قبل الـ chunk يبقى مزدوجاً.
- **حوار الحتمي:** نص وثيم مختلفان بين الستارة والأجندة. التوحيد البصري ممنوع بلا إذن.
- لا Playwright / لا جهاز / لا `tsc` كامل في هذا الإغلاق.
