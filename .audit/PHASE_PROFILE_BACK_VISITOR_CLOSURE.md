# إغلاق: زر العودة + ملف الزائر الشبكي

**التاريخ:** 2026-08-29  
**النطاق:** كروم الملف الشخصي — تعارض زر الرجوع مع صف الهوية؛ صدق عرض الصفحة للزائر بدون أدوات المالك.

---

## ما أُنجز

1. **نقل زر العودة** من `slot--start` (جانب صورة/اسم الهوية في RTL) إلى `slot--end` مع شريط التحرير — مقابل الهوية بصرياً (يسار في RTL).
2. **مسار الزائر الشبكي** مؤكَّد:
   - المنتدى: `ForumMemberProfileOverlay` → `targetUserId={userId}` → `RoyalLawyerProfile` → `readOnly={!profile.isOwnProfile}`.
   - `ProfileHeroActionRail`: للجميع / استوديو / تعديل فقط عند `!readOnly`؛ الزائر يرى متابعة إن وُجدت.
3. **غطاء الفتح:** `useProfileOpenFirstPageModel` يضبط `readOnly: !isOwnCover` ولا يفعّل طوابير التعديل/الاستوديو لغير المالك.
4. **اختبارات صدق** (18 ناجحة): كروم التخطيط، مالك/زائر على السكة، غطاء الفتح، إيماءات.

## الحدود

- لم يُعاد تصميم بصري للهيرو/السكة — نقل موضع الرجوع فقط.
- خصوصية الصفحة (`public` / مقيد) تُطبَّق عبر منطق الصفحة والـ API؛ هذا الإغلاق يضمن **عدم ظهور أدوات المالك** للزائر وليس إعادة كتابة سياسات الخصوصية.
- التحقق اليدوي على جهاز حقيقي (منتدى → ملف محامٍ آخر) موصى به بعد النشر.
