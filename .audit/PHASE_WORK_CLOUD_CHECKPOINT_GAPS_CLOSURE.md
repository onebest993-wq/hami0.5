# PHASE — إغلاق نواقص نقطة حفظ العمل السحابية

**التاريخ:** 2026-08-29  
**النطاق:** ما تبقّى بعد إدخال جدول/BFF النقطة: مسح الحساب، GET للضيف، حفظ فوري بعد الكتابة والمزامنة، صدق الاختبارات، كتالوج WIFE. لا تغيير بصري.

---

## 1. ما أُنجز

| المجال | السلوك |
|--------|--------|
| مسح الحساب SQL | `wipe_user_application_data` يحذف `lawyer_work_checkpoints` إن الجدول موجود. **مطبّق على hami 0.5** (`20260829130636`). الملف المحلي يطابق رقم النسخة البعيدة |
| مسح الحساب TS | `wipeAuthenticatedUserCloud` يحاول `from('lawyer_work_checkpoints').delete` حتى إن غاب `.from` في المحاكاة |
| GET `/api/work-checkpoints` | موضوع غير UUID (ضيف) → `{ checkpoint: null }` بلا استعلام Postgres |
| كتابة BFF حية | بعد upsert/delete دعاوى/تنفيذ/ملاحظات يُجدول `scheduleWorkCloudCheckpoint` (4 ثوانٍ؛ صامت تحت Vitest) |
| مزامنة الآن | بعد نجاح غير متخطىً: `pushWorkCloudCheckpointNow` فوراً دون انتظار المهلة |
| تعافي المخزن | `includeCloud` الافتراضي يستعيد النقطة قبل مزامنة السلة؛ الاختبارات تعزل الاستعادة |
| فيضان WIFE | `ALL_BFF_ENDPOINTS` + كتالوج المسارات يشملان GET/POST النقطة |
| كتالوج الإقلاع | `POST /api/auth/otp/preview` أُعيد إلى الـ fixture بعد إضافة المسار لقائمة الإقلاع |
