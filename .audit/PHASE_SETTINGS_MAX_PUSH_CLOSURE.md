# قسم الإعدادات — أقصى دفع مهني لمسار الفتح

> **حالة الأرشيف:** موجة ضغط جذع الفتح بعد إغلاق البقايا والعلل الخفية.  
> **سابق غير مُعاد:** حذف صفوف المنظر/الضبابية، تنحيف بصري، عزل شبكة، ختم سحابة. بلا إعادة تصميم.  
> **عقد قائم:** بلا `useLawyerSettingsCloudSync`، بلا مزامنة تفضيلات عند كل ضغطة، بلا تقويم/مهام من الإعدادات، بلا دمج قشرة الطلاء الفوري في Host React.

**التاريخ:** ٣٠ آب ٢٠٢٦  
**النطاق:** مسار فتح المركز (JS/prefetch/أيقونات/مسبار البصمة) — بلا تغيير بصري.  
**خارج النطاق:** استوديو الملف المهني، `SettingsScreens`، تشغيل `build:e2e` / Playwright حيّ / جهاز / `tsc --noEmit` صفري.

---

## صدق عن الحدود

هذه الحدود **عقد تحقق**، ليست قائمة مؤجّلة داخل المصدر:

| الحد | الحكم |
|------|--------|
| Playwright في هذه الجلسة | **لا يُشغَّل.** `npm run dev` مسار مغلق (بوابة دخول). `dist` ليست إقلاع E2E حيّاً. `build:e2e` يستبدل الحزمة — ممنوع هنا |
| `tsc --noEmit` الكامل | **ليس صفر أخطاء** (موروث). العقد: `npm run guard:tsc` |
| جهاز / متصفح يدوي | لا أدوات تصفح في الجلسة، لا هاتف |
| دمج instant-paint + React Host | لم يُمس — خطر تسليم كبير |
| تضييق keepAlive أكثر | لم يُمس — رجوع اللوحة الفارغة معروف |
| سحابة تفضيلات / تقويم-مهام | لم تُعد |
| إعادة صفوف الحجم/التباين/الأداء الخفيف/الضبابية | لم تُعد |

## ما أُنجز في هذه الدفعة

| العمل | الأثر |
|--------|--------|
| تقسيم أيقونات الجذع: `Core` / `Chrome` / `Security` / `Lazy` | هيدر + أمن لا يسحبان SVG المنظر/الحساب في مقطع الفتح. البرميل `settingsStemIcons.tsx` للاختبارات فقط |
| سلسلة لمس الترس = بوابة + شِل فقط | `settingsIntentWarm` لم يعد يستدعي `prefetchSecondarySettingsSections`. التعليق السابق كان يعد بذلك والكود يخالفه |
| `prefetchSecondarySettingsSections` = المنظر فقط | بلا بيانات/حساب/`SmartDialogContainer` في الخمول |
| `warmSettingsChunks` (لمس الترس) بلا تسخين ثانوي | `prefetchSettingsChunks` بعد تفاعل المنزل ما زال يسخّن المنظر، ويُتخطّى على الوضع الخفيف |
| مسبار البصمة عبر `scheduleIdleWork` | `reconcileBiometricSessionLockEnabled` فوري؛ `probeBiometricSession` لا يزاحم إطار تركيب الأمن |
| فروع lite/بوابة ميتة في hover | أُزيلت بعد أن صار المساران متطابقين (شِل فقط) |

قفل: `settingsMaxPushHonesty.test.ts` + تحديث `settingsSectionLoad` / `settingsIntentWarm` / `settingsOpenSnappinessHonesty` / `settingsPerformanceCloseHonesty` / `settingsVisualDensity`.

## ما رُاجع ولم يُغيَّر (عقد أو حد)

- قشرة DOM الفورية + Host React: مساران حتى التسليم. أرقام الكروم ما زالت مقفلة في `settingsVisualDensity` (مطابقة القشرة للحيّ).
- keepAlive: الأقسام المُزارة مركّبة أثناء الفتح.
- `privacyBlur` افتراضي true بلا زر. تقليل الحركة بقي في الواجهة.
- `biometricSessionService` لم يُقسَّم — مشترك مع قفل التطبيق وإعادة الضبط؛ التقسيم خارج نطاق المركز بأمان مقبول.

## المصداقية — ما لم يُنفَّذ صراحةً

- جهاز حقيقي / متصفح تفاعلي.
- دمج قشرة الطلاء الفوري في شجرة React.
- تقسيم `biometricSessionService` (WebAuthn/الجسر الأصلي) عن جذع الأمن.
- إعادة تصميم بصري أو إعادة الصفوف المحذوفة.
