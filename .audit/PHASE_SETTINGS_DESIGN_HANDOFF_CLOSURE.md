# قسم الإعدادات — إغلاق تسليم الكروم والتصميم المصرّح

> **حالة الأرشيف:** المالك أذن بتعديل التصميم ما دام يصب في المصلحة، ورفض النقص.  
> **سابق غير مُعاد:** ضغط جذع الفتح، حذف الصفوف، عزل شبكة، ختم سحابة.  
> **عقد قائم:** بلا `useLawyerSettingsCloudSync`، بلا تقويم/مهام من الإعدادات، بلا إعادة الصفوف المحذوفة، بلا دمج قشرة DOM في شجرة React.

**التاريخ:** ٣٠ آب ٢٠٢٦  
**النطاق:** كروم الفتح + هيدر حي + قفل تلقائي + فصول المنظر — إصلاح قفزة التسليم وعيوب موبايل.  
**خارج النطاق:** استوديو الملف، `SettingsScreens`، `build:e2e` / Playwright حيّ / جهاز.

---

## صدق عن الحدود

| الحد | الحكم |
|------|--------|
| Playwright / `build:e2e` | **لا يُشغَّل** — نفس عقد الجلسات السابقة |
| `tsc --noEmit` صفري | غير متحقق. `guard:tsc` كان أحمر خارج القسم في الدفعة السابقة |
| جهاز / متصفح يدوي | لا أدوات تصفح في الجلسة |
| دمج instant-paint في Host | لم يُدمج — القشرة صارت تطابق الهيدر حتى لا تقفز |
| صفوف الحجم/التباين/الأداء الخفيف/الضبابية | لم تُعد |

## ما أُنجز

| العمل | المصلحة |
|--------|---------|
| قشرة الهيدر = زر إغلاق 44px + أيقونات تبويب + عنوان | كانت القشرة بلا X وبلا أيقونات فتقفز التبويبات عند ظهور Host |
| `padding-top` من `--hami-lawyer-header-safe-top` | على Android كانت القشرة تحت شريط الحالة ثم تقفز للأسفل |
| تبويبات `min(100%, 36rem)` بدل `20rem` | نفس عرض عمود البطاقات — لا كبسولة ضيقة على اللوح |
| زر X على القشرة يغلق بعد حراسة الإيماءة (`SETTINGS_INSTANT_DISMISS_EVENT`) | قبل Host كان المستخدم يرى كروماً لا يُغلق |
| `dir` من `documentElement` | إن كان الإنجليزي مفعّلاً لا تنعكس القشرة RTL ثم تقفز |
| قفل تلقائي يلتف صفين بدل تمرير أفقي | ست شرائح على هاتف لم تكن تُقرأ |
| أيقونة مؤقّت لصف القفل | صف الأمن صار بنفس إيقاع الصفوف الأخرى |
| تلميح مرئي لفصول المنظر | كان في `aria-label` فقط |
