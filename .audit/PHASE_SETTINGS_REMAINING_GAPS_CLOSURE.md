# قسم الإعدادات — إغلاق الفجوات المتبقية بعد تسليم الكروم

> **حالة الأرشيف:** المالك طلب إكمال كل نقص/تحسين ممكن.  
> **سابق غير مُعاد:** ضغط جذع الفتح، حذف الصفوف، عزل شبكة، ختم سحابة، مطابقة قشرة الهيدر.  
> **عقد قائم:** بلا `useLawyerSettingsCloudSync`، بلا تقويم/مهام من الإعدادات، بلا إعادة الصفوف المحذوفة، بلا دمج قشرة DOM في شجرة React.

**التاريخ:** ٣٠ آب ٢٠٢٦  
**النطاق:** تبويبات القشرة قبل Host، ثبات صف البصمة، منتقي ملفات iOS، تنظيف ميت.  
**خارج النطاق:** استوديو الملف، `SettingsScreens`، `build:e2e` / Playwright حيّ / جهاز.

## صدق عن الحدود

| الحد | الحكم |
|------|--------|
| Playwright / `build:e2e` | **لا يُشغَّل** — نفس عقد الجلسات السابقة |
| `tsc --noEmit` صفري | غير متحقق في هذه الدفعة |
| جهاز / متصفح يدوي | لا أدوات تصفح في الجلسة |
| دمج instant-paint في Host | لم يُدمج — التبويبات صارت تعمل على القشرة |
| مسارات SVG المشتركة (React ↔ HTML) | لم تُوحَّد — خطر انحراف أيقونة إن تغيّر أحد المصدرين |
| `keywords` في `SETTINGS_NAV` | بلا قارئ إنتاج — أُبقي كتوثيق بحث |

## ما أُنجز

| العمل | المصلحة |
|--------|---------|
| تبويبات القشرة `pointer-events:auto` + حفظ الجلسة + حدث `SETTINGS_INSTANT_SECTION_EVENT` | لمس «المنظر» قبل Host كان ميتاً فيفتح الأمن دائماً |
| Host يزامن التبويب من الحدث، والجذع يقرأ `sessionStorage` عند التركيب | سباق التركيب لا يُسقط اختيار المستخدم |
| تسخين القسم بعد الإطار (`setTimeout(0)` + dynamic import) | لا يسحب `AppearanceSection` إلى جذع الطلاء |
| هيكل بطاقة تحت الهيدر (`settings-instant-skeleton`) | يقلّل وميض البحرية الفارغ حتى يظهر الأمن |
| `reserveSubLabel` + `min-h-[2.25rem]` لصف البصمة | المسبار الخامل كان يمدّد الصف بعد أول رسم |
| بلع click شبحي يشمل `settings-instant-close` والتبويبات | إيماءة الترس لا تغلق/تبدّل بالخطأ |
| منتقي الاستيراد `hami-settings-file-input` بدل `hidden` | `display:none` يعطّل `input.click()` على بعض WebView iOS |
| حذف `labelEn` و`nowrap` الميت | اللغة مفروضة عربياً؛ القفل التلقائي يلتف ولا يحتاج تمرير أفقي |
