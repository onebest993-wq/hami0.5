# إغلاق: اشتقاق النتيجة من إلزام/رد عند التعدد

**التاريخ:** 2026-09-03  
**النطاق:** موضوعية عادية + ≥2 مدعى عليه (بدون اختصام)

## ما أُنجز

1. **`resolveJudgmentTypeFromPartyOperatives`** — الكل ملزَم → إجابة كاملة أو جزئي موضوعي؛ مختلط → جزئي؛ الكل مبرَّأ → رد كلي.
2. **واجهة التعدد:** إخفاء الماسة؛ إلزام/رد لكل خصم؛ **بحق الملزَمين كامل/جزئي** يظهر فقط إن لم يُرد بحق أحد.
3. **مدعى عليه واحد / استئناف / تمييز / اختصام:** الماسة كما كانت.
4. اختبارات `SmartJudgmentModal` + `partyJudgmentDisposition` محدَّثة.

## الحدود

- اختصام / طعون عليا: ماسة يدوية كما قبل.
- Soft Lock / ساعات مزدوجة / EXEMPT / إضابير متوازية: ما زالت مجمّدة.
