# قسم الإشعارات — دفعة إكمال البقايا القابلة

> **حالة الأرشيف:** موجة إكمال بقايا. إغلاق القسم الحالي: `.audit/PHASE_NOTIFICATIONS_SECTION_CLOSE.md`.  
> **سابق غير مُعاد:** نظافة موجة 2، تنحيف بصري، علل خفية (تقارير مستقلة).

**التاريخ:** ٣٠ آب ٢٠٢٦  
**النطاق:** جرس الهيدر → `NotificationPanel` + `NotificationShell` + `notificationStore` + قشرة الطلاء الفوري + لوحة المفاتيح على طبقة الإشعارات.  
**خارج النطاق:** `ForumNotificationsPanel`، إشعارات التنفيذ/الورثة، منتج caseShare خارج بطاقات اللوحة.  
**بلا إعادة تصميم، بلا دمج طبقتي CSS للإخفاء، بلا دمج مساري الطلاء الفوري، بلا دمج محمّلي boot/shell.**

---

## ما أُنجز في هذه الدفعة

| العمل | الأثر |
|--------|--------|
| `listLive = isOpen \|\| snap.present` | تسلّح بطاقات الوارد وتجميعها أثناء حضور الستارة (فتح CSS/keepAlive وإغلاق متحرك) — بلا شجرة 28 بطاقة وهي مغلقة بالكامل |
| `contentArmed={listLive}` | كان `contentArmed={isOpen}` يفرّغ الجسم إطاراً بينما CSS يُظهر المضيف الدافئ |
| مصالحة `markAsRead` / `markForumNotificationsRead` | إشعار يصل أثناء `await` الحفظ لا يُفقد من الذاكرة ولا يُمسَح من القرص إن نما الطول — نفس طبقة `markAllAsRead` |
| `persistLiveListIfSameUser` | حذف/دمج لا يكتب لقطة قديمة ولا قرص مستخدم بعد تبديل الحساب |
| `applyKeptReadFlags` + `notificationStorePersist.ts` | منطق القراءة/المالك خارج zustand |
| `ignoreTasksDatePickerGrace` في لوحة الإشعارات | حقل كتم الموعد لم يعد يتجمّد إن بقيت مهلة منتقي مهام الأجندة (٤ ث) |
| ثوابت قشرة الطلاء | نصف القطر/الخلفية/العنوان مشتركة بين الجسر والورقة الحيّة — بلا تغيير بصري مقصود |
| تقرير التنحيف | صف «مسح داخل زر» صار يشير إلى إصلاح موجة العلل |

`useIncomingCaseShares` و`useNotificationPolling` بقيا على `isOpen` — لا شبكة مشاركة/نبض قبل أن تفتح React اللوحة فعلياً.

## ما رُاجع ولم يُغيَّر (عقد أو حد تقني)

- جسر الطلاء الفوري + React Host مساران؛ تكرار CSS الإخفاء في `lawyerHomeFx-critical.css`.
- محمّلان: تسخين boot مقابل مقطع الشِل.
- Motion على الورقة لسحب الإغلاق من الهيدر.
- `headerShellIntentWarm` ما زال يسخّن المقطع مبكراً.
- أيقونة كتم الهيدر = كتم الجلسة لا ساعات الهدوء.
- `handleTap` يغلق اللوحة حتى بلا هدف تنقّل — سلوك منتج.
- `ForumNotificationsPanel` خارج النطاق.

## الحدود — ما لم يُنفَّذ صراحةً

- Playwright و`tsc --noEmit` كامل وجهاز ومتصفح تفاعلي: غير منفَّذة — لا ادّعاء جاهزية أصل.
- بطاقات مشاركة الإضبارة ما زالت تنتظر `isOpen` (عقد عزل الشبكة) — قد تبقى ومضة قصيرة لقسم المشاركة دون الوارد.
- لا دمج جسر/Host، لا دمج CSS الإخفاء، لا دمج المحمّلين.
- `.audit/import-closure-report.json` قد يذكر مسارات محذوفة تاريخياً — إعادة توليد التقرير عملية على مستوى المستودع ولم تُنفَّذ هنا.
