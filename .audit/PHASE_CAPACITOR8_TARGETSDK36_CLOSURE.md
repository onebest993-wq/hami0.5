# إغلاق مرحلة: بوّابة النشر — Capacitor 6→8 و targetSdk 34→36

**التاريخ:** ٨ آب ٢٠٢٦
**السبب:** Google Play يرفض أي تقديم لا يستهدف API 36 بعد ٣١ آب ٢٠٢٦. التطبيق كان على 34 — أي أنه **لم يكن قابلاً للنشر أصلاً**، لا بطيئاً ولا ناقصاً.

---

## ما أُنجز

### ١. حزم npm — ترقية وتثبيت

| الحزمة | قبل | بعد |
|---|---|---|
| `@capacitor/core` `android` `ios` `cli` | 6.2.1 | **8.5.0** (مثبّتة بلا `^`) |
| `@capacitor/app` | 6.0.2 | 8.1.1 |
| `@capacitor/keyboard` | 6.0.4 | 8.0.5 |
| `@capacitor/share` | 6.0.4 | 8.0.1 |
| `@capacitor/filesystem` | ^6.0.4 | ^8.1.2 |
| `@capacitor/geolocation` | ^6.0.2 | ^8.2.1 |
| `@capacitor/local-notifications` | ^6.1.3 | ^8.2.1 |
| `@capacitor-community/privacy-screen` | 5.2.1 | 8.0.0 |
| `@aparajita/capacitor-biometric-auth` | ^8.0.2 | ^10.0.0 |
| `@capacitor/status-bar` | 6.0.3 | **محذوفة** |

التثبيت بلا `^` مقصود: ملحقات Capacitor تنكسر عبر الإصدارات الثانوية، والحارس يفرضه.

### ٢. سلسلة البناء الأصلية

- `minSdkVersion` 22 → **24**، `compileSdk`/`targetSdk` 34 → **36**
- AGP **8.13.0** + Gradle **9.5.1** (AGP 9 يكسر ملحقات Capacitor بتعارض إضافة Kotlin)
- `foojay-resolver-convention` في `settings.gradle` — يُنزّل JDK 21 تلقائياً بدل فشل «Cannot find a Java installation»
- كل ملفات Gradle (`variables` `build` `settings` `gradle-wrapper.properties`) صارت **قوالب** تُنسخ عند `cap:apply:android`، فلا ينسفها إعادة التوليد

### ٣. شريط النظام — تكيّف مع الحافة الكاملة

أندرويد ١٦ يفرض edge-to-edge ولا يقبل انسحاباً. `StatusBar.setOverlaysWebView` و`setBackgroundColor` صارتا بلا أثر — بقاؤهما كان سيوهم بضبطٍ لا يحدث.

- حُذفت حزمة `@capacitor/status-bar` وإعدادها من `capacitor.config.ts` و`vite.config.mts` والـshim
- `capacitorShellBoot.ts` ينادي `SystemBars.setStyle` من النواة
- `configChanges` أُضيف إليها `navigation|density` (واجب منذ Capacitor 8 — دونها يُعيد أندرويد إنشاء النشاط عند تغيّر الكثافة، أي إقلاع كامل يفقد الإضبارة المفتوحة)
- الحشوات الآمنة (`env(safe-area-inset-*)`) كانت **موجودة سلفاً** على كل السطوح الحرجة: قشرة الإقلاع، الرصيف السفلي، الأوراق، النوافذ، المنتدى، الإعدادات، الملف الشخصي. لم يُضف حشو جديد ولم يُغيَّر شكل.

### ٤. التحقّق من الثنائي — لا من الملفات

بُني APK فعلياً وفُحص البيان المدمج بـ`aapt2`:

```
package: name='iq.hami.legal' compileSdkVersion='36' compileSdkVersionCodename='16'
minSdkVersion:'24'
targetSdkVersion:'36'
uses-permission: name='android.permission.USE_FINGERPRINT' maxSdkVersion='27'
```

### ٥. الحارس — كي لا يتكرر

`guard-native-foundation.mjs` صار يشتقّ المطلوب من النسخة المثبَّتة بدل رقم مكتوب باليد:

- خريطة `Capacitor major ↔ targetSdk` (6↔34، 7↔35، 8↔36) تُفحص على **القالب والمولَّد معاً**
- `minSdkVersion` كذلك
- `configChanges` يجب أن تحوي المفاتيح العشرة كاملة
- `android:screenOrientation` ممنوع (أندرويد ١٦ يتجاهله على الشاشات الكبيرة)
- فحص أقران `privacy-screen` صار يقارن بالنسخة الفعلية بدل السلسلة الثابتة «6»

| **أداء** | ٩/١٠ | المسار الحرج للإقلاع ٥٧٫٨ ك.ب مضغوطاً (الميزانية ١٩٠). البناء أخضر. لم يُقَس أثر SDK 36 على جهاز حقيقي — لا جهاز أندرويد ١٦ متاح. |
| **نظافة** | ٩/١٠ | حزمة مهجورة كاملة أُزيلت مع كل أثرها (إعداد، alias، shim، نداءات). ملفات Gradle صارت قوالب فلا ازدواج بين المولَّد والمصدر. |

| **جودة كود** | ٨/١٠ | الحارس يشتقّ بدل أن يُثبِّت، فيتقدّم مع الترقية القادمة تلقائياً. |

| **صدق** | ١٠/١٠ | الحدود أدناه مذكورة بلا تجميل. |

## الحدود — ما لم يُنفَّذ

1. **لا اختبار على جهاز/محاكٍ أندرويد ١٦.** التحقّق كله ثابت (aapt2 على البيان المدمج) وليس تشغيلياً. أول تشغيل فعلي قد يكشف تداخل شريط التنقّل مع الرصيف السفلي على أجهزة بإيماءات، أو سلوك لوحة مفاتيح مختلفاً. هذا **فحص واجب قبل الرفع**، لا خيار.
2. **iOS لم يُولَّد.** يحتاج macOS. القوالب جاهزة (`biometric-ios-Info.plist.snippet.xml`) لكن لا شيء مُتحقَّق منه.
3. **APK تصحيحي لا إصداري.** التصغير والتوقيع والـR8 لم تُختبر بعد؛ قد تُظهر مشكلات proguard مع الملحقات الجديدة.
4. **`versionCode` ما يزال 1.** يجب رفعه قبل أول رفع.
