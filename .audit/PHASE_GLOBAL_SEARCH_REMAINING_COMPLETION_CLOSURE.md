# قسم البحث الشامل — دفعة إكمال البقايا القابلة

> **حالة الأرشيف:** موجة إكمال بقايا. سابق غير مُعاد: نظافة، تنحيف بصري، علل خفية (تقارير مستقلة).  
> **النطاق:** عدسة الهيدر → `GlobalSearchOverlay` + تسخين الفهرس/extras + Fuse + قشرة الطلاء الفوري.  
> **خارج النطاق:** بحث المنتدى داخل المجتمع، بحث المستودع الذكي، بحث الأرشيف، عزل قرص مهام الكمّ.  
> **بلا إعادة تصميم، بلا دمج مساري الطلاء الفوري (HTML + React Host)، بلا سحب Fuse إلى مسار العدسة.**

**التاريخ:** ٣٠ آب ٢٠٢٦

---

## ما أُنجز في هذه الدفعة

| العمل | الأثر |
|--------|--------|
| extras ديناميكية (`lawyer-cloud` / vault / forum) | تسخين الخمول لا يسحب مستودع المنتدى ومنشوراته إلى المسار الساخن |
| `warmFullIndex` و`warmGlobalSearchExtras` بـ `includeCommunityPosts: false` | الورقة عند الفتح ما زالت تطلب المجتمع عبر `OVERLAY_EXTRAS_OPTIONS` |
| `isSearchIndexKeyExtrasOnlyChange` + `keepVisibleIndex` | وصول extras لا يفرّغ نتائج الملفات (مؤشر تحميل كامل فقط عند تغيّر البادئة: ملف/حساب/ملاحظات) |
| `preparedStoredNotes = []` في التحضير | لا قراءة ثانية غير مقيّدة لـ `lawyer_notes`؛ المصدر الحي `globalNotes` من اللوحة |
| `globalSearchFuseRank.ts` | ترتيب/مسح Fuse خارج كاش المحرك |
| `searchInstantChromeClasses.ts` | رأس حي + قشرة React + HTML الطلاء نفس سلاسل الصفوف (١٦px / ٤٤px) |
| `setRecentSearches((prev) => …)` | نقران سريعان لا يكتبان قائمة «الأخيرة» من لقطة بائدة |

---

## ما رُوجع ولم يُغيَّر (عقد أو حد تقني)

- جسر `innerHTML` (`globalSearchInstantSheetHtml.ts`) و`GlobalSearchInstantSheetChrome` مساران عمداً — الدمج يسحب Fuse إلى العدسة.
- تجميد CSS في `lawyerHomeFx-critical.css` و`gsLayer.css`.
- مهام الكمّ ما زالت تُحمَّل في extras من مفتاح جهاز (`hami_quantum_legal_tasks_v1`) — قسم المهام.
- `RepositoryDB.listDocuments()` يبقى عند فتح الورقة (`includeCommunityPosts: true`).
- لا دمج instant-paint مع Host.

## الحدود — ما لم يُنفَّذ صراحةً

- تكلفة Fuse/الفهرس عند أول فتح تفاعلي ما زالت موجودة؛ التسخين يخفّف ولا يلغي.
- Playwright و`tsc --noEmit` كامل وجهاز ومتصفح تفاعلي: غير منفَّذة — لا ادّعاء جاهزية أصل.
- لا عزل مهام الكمّ على القرص من هذا القسم.
- لا دمج مساري الطلاء، لا تغيير بصري مقصود.
