# إغلاق قسم — المهام: العزل شبكي لا تشفيري

**التاريخ:** ٣٠ آب ٢٠٢٦  
**النطاق:** بلاطة `dockTasks` / ستارة الميدان / أجندة المهام (`TasksManager`) / تخزين `hami_quantum_legal_tasks_v1`.  
**العقد:** قطع الشبكة في المسار اليومي؛ التشفير عند الراحة يبقى؛ WIFE لا يدخل الحفظ المحلي. الشبكة فقط خلف `isLawyerWorkCloudLive` لطلب العون الصريح، لا لمزامنة أجندة المهام مع نقطة حفظ الإضابير.

---

## القرار وسببه

توجيه المالك: لا إنترنت ولا تشفير ولا WIFE في المهام — الحماية هي القطع التام، والشبكة فقط لمزامنة الإضابير.

نفس درس المعاملات في اليوم السابق: «لا تشفير» إن فُهم حرفياً يُسقط AES المحلي عن أسماء الموكّلين، ويُبطل تشفير التقويم إن عادت مزامنة العناوين. التشفير ليس شبكة ولا يحتاج Wi‑Fi.

| الطبقة | القرار |
|--------|--------|
| قطع الشبكة + WIFE خلف بوابة المزامنة | **مُطبَّق** على المسار اليومي؛ طلب العون لا يضرب `/api/task-help` ولا المنتدى ولا شبكة الزملاء ما لم تكن مزامنة العمل حيّة |
| تشفير الراحة | **أُبقي وأُقوّي** — `isEncryptOrFailStorageKey` للمهام وطلبات العون |
| نقطة حفظ الإضابير (`workCloudCheckpoint`) | **لا تُضاف المهام** — ليست مزامنة إضبارة |

## ما أُنجز

| المجال | السلوك |
|--------|--------|
| `TaskHelpApiService` | `canReachTaskHelpNetwork()` = `isLawyerWorkCloudLive()` — بلا fetch ولا `assertRecipientInNetwork` في الوضع المحلي |
| `executeRequestTaskHelp` | منشور المنتدى فقط ومزامنة العمل حيّة |
| `RequestHelpModal` | لا تحميل زملاء من الشبكة محلياً؛ الإرسال معطّل؛ تلميح بنفس نمط وصف الحوار |
| تشفير | `hami_quantum_legal_tasks_v1` و`hami_task_help_requests_v1` داخل `isEncryptOrFailStorageKey` |
| حارس المسح | `isTaskHelpRequestsKey` — رفض التفريغ فوق ciphertext بارد؛ المسح المتعمَّد لـ `[]` يبقى ممكناً |
| leftover | `writeSecureAndClearLegacySync` لا يمحو المرآة إن فشلت الكتابة |
| حفظ ثم ستارة | بعد `persistQuantumTasksSync` يُملأ الكاش الدافئ — بلا `getItemSync` على أول إطار (عقد الإقلاع) |
| جسر التقويم | `patchFieldTaskDue` عبر `persistQuantumTasksSync` + حدث التغيير؛ المسار الحي ما زال `void params.fieldTasks` |
| تقسيم | `TasksManagerModalFields.tsx` — حقول التعديل/التأجيل خارج ملف الحوارات (~316 سطراً بعد ~450) |
| موبايل | `enterKeyHint` على طلب العون وحقول التعديل |

## الحدود

| الحد | السبب |
|------|--------|
| قراءة أول إطار من leftover لا من SecureStore | عقد الإقلاع: `getItemSync` على mount الـ Provider ممنوع (`QuantumTasksProvider.persistence` + wave3). بعد محو المرآة، الجلسة التالية تنتظر hydrate غير متزامن؛ شارة الدوك من لقطة الإطار إن وُجدت |
| المهام ليست في `workCloudCheckpoint` | ليست مزامنة إضبارة. إضافتها توسّع السطح الشبكي بلا قرار منتج |
| `syncFieldTasksToCalendar` ما زال موجوداً للاختبارات/الأدوات | المسار الحي لا يستدعيه — مقفول باختبار أمانة |
| `TaskCard.tsx` 444 سطراً | التقسيم الإضافي يمسّ هيكل البطاقة البصري |
| تلميح طلب العون عند قطع الشبكة | نص وظيفي بنفس `TASKS_DIALOG_DESC` — ليس إعادة تصميم للستارة/الأجندة |
| لم يُفتح المتصفح لتدقيق الحوار | لا أدوات متصفح في هذه الجلسة؛ الخادم المحلي يعمل ولم يُمرَّر مسار العون يدوياً |

## الموقع

**جاهز للانتقال: نعم** ضمن الحدود. المسار اليومي للمهام محلي ومشفَّر؛ WIFE والـ API لا يدخلان إلا طلب عون صريح ومزامنة العمل حيّة.

## المصداقية — ما لم يُنفَّذ

- لا مزامنة سحابية لأجندة المهام حتى مع `cloudSync` (مقصود).
- لا إسقاط لتشفير الراحة.
- لا قياس هاتف/لوحة، لا E2E Playwright لهذا الإغلاق، لا حملة `tsc` الكاملة.
- `wave7cSealClosersHonesty` ما زال يتوقع `requireWifeUser` في `_auth` بينما التنفيذ `requireWifeCloudWrite` — إخفاق سابق خارج هذا العمل، لم يُلمَّع.
