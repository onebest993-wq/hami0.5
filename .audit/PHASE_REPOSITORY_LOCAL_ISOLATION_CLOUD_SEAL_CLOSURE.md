# إغلاق قسم — المستودع الذكي: قطع الشبكة + تشفير الفهرس + ختم السحابة

**التاريخ:** ٣٠ آب ٢٠٢٦  
**النطاق:** بلاطة `dockRepository` / المستودع الذكي + مخزن الملفات المحلي (`SmartVault`).  
**القرار:** توجيه المالك «لا إنترنت ولا تشفير ولا WIFE — الحماية هي القطع التام، والشبكة فقط لمزامنة الاضابير». نُفِّذ كما في المعاملات: **العزل شبكي**؛ تشفير الراحة للفهرس يبقى؛ blobs بلا تشفير JS.

---

## القرار وسببه

| الطبقة | ما تحمي منه | القرار |
|--------|--------------|--------|
| قطع الشبكة + WIFE خلف بوابة مزامنة العمل | تسريب إلى خادم، توقيع الطلبات | **مُثبَت سابقاً** عبر `isLawyerWorkCloudLive` — لم يُمسّ بروتوكول WIFE |
| تشفير الراحة لفهرس الأسماء/الغرف/التصنيفات | نسخ IndexedDB من جهاز مسروق | **أُبقي** — نفس سرّ أسماء الموكّلين |
| تشفير JS لملفات PDF/مسح | لا شيء إضافي فوق تشفير نظام التشغيل | **مرفوض** — IDB يخزّن `Blob` خام |
| حمولة KV عند تفعيل المزامنة | عناوين وOCR نصاً صريحاً خلف kv-proxy رغم WIFE | **أُغلق في هذه الجلسة** — ختم `encrypted_data` + حذف OCR |

---

## ما أُنجز في هذه الجلسة

| المجال | السلوك |
|--------|--------|
| `workCloudKvSeal.ts` | غلاف KV مشترك: `seal` / `unseal` + قبول إرث صريح |
| `vaultCloudKvPayload.ts` | حذف `extractedText` و`signedUrl` و`isProcessing`؛ تعقيم الملاحظة؛ دمج يحفظ OCR المحلي |
| `smartVaultRuntime.ts` | `kv.set` لا يستقبل وثيقة صريحة؛ القراءة تفكّ الغلاف |
| `lawyer-cloud.ts` `RepositoryDB` | نفس الختم لمفاتيح `repository:docs:` (نسخة المحامي عبر الأجهزة، ليست كتالوجاً عاماً) |
| `useVaultDocDisplayUrl.ts` | لا يزرع `javascript:` في `<img src>` |
| `repositoryRoomPresentation.ts` | معرفات التثبيت عبر SecureStore تحت `hami:repository:rooms:pinned:` |
| `removeRemoteStoragePaths.ts` | مسار حذف سحابي واحد للمخزن؛ المنتدى يبقى بلا بوابة عمل (يحتاج شبكة بطبيعته) |
| تصديرات ميتة | حُذف `forceRefreshVaultDocs` و`isVaultDocAudio` |

لا تغيير بصري.
