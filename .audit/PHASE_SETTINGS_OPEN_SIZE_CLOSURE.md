# قسم الإعدادات — حمولة الفتح لا حجم المصدر

> **حالة الأرشيف:** موجة التعامل المهني مع الحجم بعد سؤال المالك.  
> **سابق غير مُعاد:** توحيد عقدة الـ overlay، قشرة فورية، حذف صفوف المنظر/الضبابية، تنحيف بصري.  
> **عقد قائم:** بلا `useLawyerSettingsCloudSync`، بلا مزامنة تفضيلات عند كل ضغطة، بلا تقويم/مهام من الإعدادات، بلا دمج قشرة الطلاء في Host React، بلا `build:e2e`.

**التاريخ:** ٣١ آب ٢٠٢٦  
**النطاق:** متى يُحمَّل مقطع المنظر، واستيراد جذع الشِل. بلا تغيير بصري.  
**خارج النطاق:** استوديو الملف المهني، `SettingsScreens`، تشغيل `build:e2e` / Playwright حيّ / جهاز / `tsc --noEmit` صفري / قياس gzip لمقطع إنتاجي في هذه الجلسة.

## صدق عن الحدود

| الحد | الحكم |
|------|--------|
| Playwright / `build:e2e` / جهاز | **لم تُشغَّل** |
| `vite build` لقياس gzip | **لم يُشغَّل** — `npm run dev` حيّ؛ الرقم أدناه من بناء سابق في `.audit/_gate_execution_latest.txt` مرجعاً لا قياساً جديداً |
| `tsc --noEmit` صفري | **غير متحقق** — موروث |
| دمج instant-paint + React Host | لم يُمس |
| قصّ منتج المنظر/النسخ/الوثائق | لم يُقص |

## ما أُنجز

| العمل | الأثر |
|--------|--------|
| حذف `prefetchSecondarySettingsSections` | لا تسخين تخميني للمنظر بعد خمول المنزل أو بعد فتح الأمان |
| `prefetchSettingsChunks` أُزيل | أول تبويب + `onDashboardInteractive` يسخّنان الشِل فقط |
| `useSettingsSectionWarm` = التبويب النشط فقط | استعادة المنظر ما زالت تحمّله؛ الأمن لا يسحب المنظر في الخمول |
| نية التبويب: `pointerenter` / `focus` / `pointerdown` / أسهم لوحة المفاتيح | المنظر/البيانات/الحساب تُحمَّل عند القصد |
| `settingsShellChrome.ts` | لون الكروم من `surfaceApplyTarget` بلا برميل الخدمات |
| حذف `settingsShellStyle.ts` + اختباره | `resolveSettingsShellStyle` لم يكن مربوطاً بالشِل الحيّ |
| الشِل/الهيدر/الأمن يستوردون `nav.ts` مباشرة | بلا `from '@/app/services/settings'` على جذع الكروم |

مرجع بناء سابق (ليس قياس هذه الجلسة): `AppearanceSection` ≈ **16.2 ك.ب / 6.3 ك.ب gzip**. هذا ما كان يُسحَب بعد تفاعل المنزل على الأجهزة غير الخفيفة، حتى إن لم يفتح المحامي تبويب المنظر.
