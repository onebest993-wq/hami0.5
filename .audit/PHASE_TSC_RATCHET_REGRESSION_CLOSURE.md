# إغلاق: إصلاح انحدار مِسنَنة الأنواع (خارج المدني)

تاريخ: 2026-09-02

## النطاق

إصلاح أربعة ملفات كانت تزيد أخطاء الأنواع عن الخط الأساس وتُسقط `guard:tsc` في بوابة الجودة. **لم يُمسّ محرّك الحكم المدني ولا التجميد.**

## ما أُنجز

- متابعة الحجز: محاذاة توست/إكمال الحجز/تبويب المحضر مع أنواع المصدر؛ محوّل `adaptFollowupSeizureShowToast` بدل تمرير دالة أضيق إلى توقيع أوسع.
- جسر التقويم: تحويل `Record` → `FileData` عبر `unknown` كما يطلب المصرّف. اختبار التقويم كان يزرع عبر `saveLawsuitFilesRaw` بينما الكتابة تقرأ المقطع النشط — أُصلح الزرع والقراءة عبر بوابة المتانة.
- مرفقات المنتدى: `src/lib/forumService.d.ts` بجانب `forumService.js` (نفس نمط `syncService.d.ts`).
- التخزين الآمن: بوابة الكتابة الذرّية لا تُسند `resolve` الخاص بـ`Promise` إلى `() => undefined`.

`guard:tsc`: 1195 → 1166، بلا انحدار. خُطّ الأساس بـ`--save`.

17 اختباراً مستهدفاً أخضر (كفيل المتابعة، المرفق، forumService، جسر التقويم).
