# إغلاق: عقد تخزين الدعاوى الذرّي (سلة / استعادة / حذف نهائي)

تاريخ: 2026-09-01

عقد الإغلاق: `e2e/lawsuit-storage-lifecycle.spec.ts` على preview بعد `npm run build:e2e`.

**جاهز للانتقال: نعم** لهذا العقد على Chromium preview. المراجعة بعد الإغلاق الأول وجدت نواقص حقيقية وأُغلقت قبل إعادة التحقق.

## ما أُنجز

- COMMIT عبر `executeLawsuitLifecycleTransaction` مع تثبيت مفتاح AES.
- المواصفة تقرأ `getItemFromDisk`.
- `lawyer_files = []` المقروء حقيقة معتمدة — لا دمج `lawsuitFiles` / المفاتيح القديمة.
- شواهد الحذف تُسقط الصف قبل الحفظ، وتُفرَّغ المرآة القديمة مع المونولث.
- أي `setItem` انتظر حاجز المعاملة يُسقط بعد COMMIT (ليس `lawyer_files` فقط) — وإلا `[]` كان يمسح الشواهد.
- الحذف النهائي/الاستعادة يرفضان إن بقيت الشواهد unread (لا كتابة `["id"]` فوق قائمة أقدم).
- النسخة الاحتياطية لا تُستعاد فوق تفريغ مقروء، ولا فوق أصل unread، ولا تعيد صفوفاً عليها شاهد.
- تحميل المفتاح الأساسي موحّد في `resolveLoadedDossierPrimary`.
