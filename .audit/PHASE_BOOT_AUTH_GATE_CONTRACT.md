# إغلاق — مسار الإقلاع وبوابة الدخول (عقد هندسي)

تاريخ: 2026-08-11

## التشخيص (جذر واحد)

الرعشة لم تكن «أنيميشن ناقص»، بل **تعارض عقدين بصريين**:

1. شعار HTML كبير «حامي» (system-ui)
2. عنوان React مكرر «حامي» بحجم/خط مختلف داخل البطاقة عند كشف الطبقة

مع تحميل Tajawal لاحقاً على `body` → FOUT على نص البطاقة.

محاولات سابقة (إخفاء الشعار، تأخير، تأجيل الخطوط) كانت ترقيعاً وأفسدت إحساس الإقلاع.

## العقد المنفَّذ

| العنصر | القرار |
|--------|--------|
| wordmark «حامي» | مرة واحدة فقط في `#hami-static-boot` |
| بوابة الدخول | عنوان إجرائي «أهلاً بك» — بلا wordmark مكرر |
| سطح البوابة | CSS واحد `authGateSurface.css` + أصناف مستقرة |
| كشف الطبقة | إطاران → إزالة فورية — بلا تأخير اصطناعي |
| html rem | 16px ثابت؛ مقياس القراءة عبر `--hami-font-size` فقط |
| قفل الطباعة أثناء الإقلاع/البوابة | `bootTypographyLock.ts` |
