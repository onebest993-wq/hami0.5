# إغلاق: حفظ حكم واحد ثم مسارات التذييل (لا كاسب/خاسر)

**التاريخ:** 2026-09-03

## ما أُنجز

1. **مودال الحكم:** زر أساسي واحد «حفظ الحكم» يُقفل المنطوق — بلا ثنائية كاسب/خاسر أو طعن/انتظار متنافسة.
2. **اعتراض غيابي:** اختياري فوري فقط إن الموكل مدعى عليه غائب وملزَم.
3. **scenarioWaitAppeal:** `both_paths` / جزئي يضبط `awaitingOpponentAppeal=true` مع `clientStageOutcome=PARTIAL`.
4. **تذييل ما بعد الحكم:** لوحة مزدوجة للجزئي — «تقديم طعن» + «قام الخصم بالطعن» معاً (لا يخفي أحدهما الآخر).
