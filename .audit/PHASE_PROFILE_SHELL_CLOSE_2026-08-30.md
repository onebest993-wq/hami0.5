# إغلاق الملف المهني — ٣٠ آب ٢٠٢٦

**النطاق:** مسار الفتح/الإغلاق + غطاء الصفحة الأولى + بوابة الوحدة. بلا إعادة تصميم بصري.

## ما أُنجز (ملموس)

1. **حذف rAF الميت** في `profileShellSnap.ts`: `scheduleProfileShellReactSync` / `shellSyncGen` لم يعودا يُستدعيان من الإنتاج (الفتح `flushSync`).
2. **مسار فتح واحد:** prefetch + hub عبر `prefetchProfileShellChunks` داخل ميكروتاسك واحد — بلا تحميل Hub مزدوج وبلا `deferProfileOpenWarmWork`.
3. **مسار إغلاق واحد:** `finishProfileShellClose` يشارك conceal → flushSync → تحرير القفل بين `commitProfileClose` و`commitProfileOverlayDismiss`.
4. **غطاء الزائر:** `readOnly` + عدم اصطفاف نية تعديل/استوديو إن لم يكن المشاهد هو المالك.
5. **البوابة:** مسارات snap/إغلاق/غطاء + عقود الإغلاق والخمول ورؤية الهيدر التي كانت خارج `gate:profile`.

## إثبات
