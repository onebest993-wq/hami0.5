# تنحيف قسم المهام — إغلاق كثافة بصرية

**التاريخ:** ٣٠ آب ٢٠٢٦  
**النطاق:** ستارة الميدان + أجندة المهام (`tasksBoucleTheme`، البطاقات، القشرة الفورية، Android FX). إذن بصري صريح من المستخدم. بلا تغيير عقد الشبكة/التشفير.

## ما أُنجز

- ثيم مضغوط: `rounded-xl`، حشو `px-3`، بلا ظل ستارة، أزرار إدارة 44px لا 48px.
- بطاقة المهمة: بلا شريط تدرج، بلا حلقة إنهاء داخلية، مصروف/تذكير/تثبيت بالذهب لا الكهرمان، ملخص بلا زجاج متداخل.
- تقسيم: `TaskCardToolRow` + ربط `useTaskCardChrome` (كان ميتاً).
- ستارة: بلا شارة «ستارة» المكررة؛ بطاقة أنحف؛ `contain-intrinsic` 6.5rem.
- أجندة: رأس بلا سطر «الأسبوع الحالي»؛ أيام/مؤجلة/أرشيف/حتمية أنحف؛ نقطة الحتمي بلا توهج.
- قشرة فورية متطابقة (`TasksManagerOpenInstantChrome` + `tasksManagerInstantPaint`).
- Android: ظل إسقاط البطاقات أُزيل (inset فقط).

## الاختبارات

Vitest: `tasksVisualLite` + `tasksVisualDensity` + `tasksMobileHonesty` + instant paint + android FX + dock surgical + مجلد `tasksManager/__tests__` + عزل الشبكة + `fieldCurtain` — **كلها ناجحة** (53 في مجلد المهام + العزل).

**لم يُنفَّذ:** قياس أداء جهاز، E2E ستارة/أجندة، تنحيف حوارات المساعدة أكثر من الثيم، قائمة الخيارات ما زالت بظل عائم خفيف (ضروري للطبقة).
