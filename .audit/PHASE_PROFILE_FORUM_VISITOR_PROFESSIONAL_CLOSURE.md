# إغلاق — إتقان مسار الزائر / الملف / المنتدى

**التاريخ:** 2026-08-30  
**النطاق:** عقد اختبار للخطافات، fail-closed لملكية الغطاء، طبقة ملف الزائر كحوار، وإصلاح عقد صلاحية المنتدى.

## ما أُنجز

1. **`forumE2eForceOpen.ts`:** تسليح stub وإعادة تسليحه بعد cleanup الحي — بلا تكرار أنواع النافذة.
2. **غطاء الملف fail-closed:** بلا مشاهد معروف أو مشاهد ≠ المالك → `readOnly` + كاش وفق `viewerId` الحقيقي (لا `viewerId: uid` الكاذب).
3. **طبقة الزائر:** `role="dialog"` + `aria-modal` + `useBodyScrollLock` (قفل تمرير للموبايل، بلا تغيير بصري).
4. **عقد صلاحية المنتدى:** mock `_auth` عبر `importOriginal` حتى يبقى `forumCatchJsonResponse` في اختبارات 403.
5. **البوابات:** `gate:profile` و`gate:forum` يضمّان الملفات/الاختبارات الجديدة.
