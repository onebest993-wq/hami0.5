# إغلاق — تخزين/حذف الإضابير (ختم دورة الحياة)

## الأعراض
1. اختفاء بعد Reload
2. زر الحذف (عادي/نهائي) لا يحذف فعلياً
3. إضبارة محذوفة تعود (سحابة/نقطة حفظ/مرآة)

## ما أُغلق في هذا الختم

| ثغرة | الإصلاح |
|------|---------|
| نقل للسلة يفرّغ النشط ثم تفشل كتابة السلة | السلة/الأرشيف أولاً ثم تقليص النشط؛ فشل الكتابة يُبقي الحالة السابقة |
| الحذف النهائي يحدّث الواجهة رغم فشل القرص | `removeLawsuitSegmentRecords` يعيد `{ok}`؛ لا قطع محلي إن فشلت الكتابة |
| الحذف النهائي دون شاهد → إحياء من السحابة | لا يُقطع من السلة إلا المعرّفات التي ثُبّت شاهدها |
| مفتاح السلة unread أثناء الحذف النهائي | `warmKeys` قبل القطع المحلي |
| دمج سحابة/نقطة حفظ يعيد المحذوف كنشط | `preferActive` = نشط القرص فقط + تصفية tombstone من كل المقاطع |
| `collectLawsuitLocalRowsForSync` يرفع المحذوف | `excludeTombstonedLawsuitFiles` |
| استعادة/نقطة حفظ بلا تصفية شواهد | تصفية بعد `ensureLawsuitDossierTombstonesReadable` |
| تقويم يدمج المرآة الكاملة فيُحيي محذوفاً | تعديل النشط الحي فقط؛ رفض إن وُجد شاهد |
| استعادة من السلة تترك شاهداً | `clearLawsuitDossierTombstone` |
| فتح السلة يظهر محذوفاً نهائياً | التحميل يصفّي الشواهد |
| شواهد unread + استيراد المرآة | fail-closed: لا دمج/لا استيراد مرآة حتى تُقرأ الشواهد |

ختم الريلود السابق ما زال قائماً: `[]` فوق ciphertext = unread، إثبات `allowShrink`، الإقلاع لا يكتب تقلّصاً أعمى.

## التحقق
216 اختباراً ذات صلة نجحت (domain/lawsuit + mutations + tombstones + checkpoint + wipe guard).

## حدود الصدق
- بيانات **مُسحت مسبقاً** من IndexedDB والسحابة لا تُستعاد بهذا الختم.
- النقل للسلة أثناء مفتاح سلة unread يُرفض (لا مسح) حتى يسخن التخزين — أصدق من اختفاء صامت.
- شواهد الحذف لا تُسخَّن في أول إطار (عقد أداء الإقلاع)؛ الدمج السحابي والاستعادة ينتظران القراءة.
