# إغلاق قسم المستودع الذكي — مصدر الحقيقة

**التاريخ:** ٣٠ آب ٢٠٢٦  
**النطاق:** بلاطة `dockRepository` / المستودع الذكي (`SmartRepository` + `SmartRepositoryModal` + ألواح المخزن التي يستهلكها + `src/app/services/repository` + صدفة الفتح/التسخين).  
**خارج النطاق:** منتدى `CommunityScreen/LegalRepository`، أجندة المهام، فك WIFE/الشبكة.

هذا الملف **يلغي اعتماد جداول الحدود القديمة** في تقارير الموجات كحالة حالية. الموجات تبقى أرشيفاً لما نُفّذ متى.

## ما أُكمل في دفعة الإغلاق هذه

| العمل | الأثر |
|--------|--------|
| `discardOrphanComposeAttachment` | إن رُفع المرفق وفشل `onSaveNote` تُحذف وثيقة المخزن ولا تبقى يتيمة |
| فشل التثبيت بعد نجاح الحفظ | توست صريح + إغلاق المسودة؛ لا يُحذف المرفق |
| `id` ملاحظة الدعوى رقم | إصلاح `TS2322` من تحويل الإلحاق إلى `{ file, noteId }` |
| أرشيف الموجات | شريط يحيل إلى هذا الملف حتى لا تُقرأ حدود قديمة كواقع |
| `npm run gate:repository` | **PASSED** — ٢٤٩ اختبار وحدة |
| E2E رسمي Chromium | **٢٤ / ٢٤ نجحت** (`smart-repository` + `repository-media` + `smart-vault` + `notepad-modal`) عبر `build:e2e` ثم preview على `:8090` |

محاولة E2E على `npm run dev` **رُفضت عمداً** (بوابة تسجيل الدخول). هذا عقد حزمة E2E لا علة منتج. محاولة أولى للمسار الرسمي فشلت لأن `:8090` كان مشغولاً — أُعيد التشغيل بعد البناء فنجح.

## التحقق — ما ثبت وما لم يُثبت

| الفحص | النتيجة |
|--------|---------|
| بوابة الوحدة `gate:repository` | PASSED (٢٤٩) |
| Playwright Chromium — سكربت المستودع الرسمي | ٢٤ نجحت (~٦.٤ دقائق) |
| Playwright `mobile-chrome` / `mobile-safari` | **لم تُشغَّل** في هذه الدفعة |
| `release:check:repository` كامل (يشمل `test:e2e:boot`) | **لم يُشغَّل** |
| `tsc --noEmit` صفر أخطاء للمستودع | **لا** — أخطاء `RefObject \| null` مقابل `LegacyRef` ما زالت في ratchet المشروع (إرث React types). خطأ `id: string` على ملاحظات الدعوى **أُصلح** |
| جهاز حقيقي / Capacitor | **لم يُشغَّل** |
| متصفح تفاعلي بأدوات الجلسة | **لا أدوات تصفح في هذه المتابعة** |

## ما يبقى حداً — ليس «لاحقاً داخل القسم» إن كان ممنوعاً أو خارج القدرة

- قائمتا الخلاصة وشريطا المحرّر: مساران حيّان؛ الدمج يحتاج إذناً بصرياً.
- تراجع حذف الغرفة / ربط الإضبارة: متسلسل أفضل جهد، ليست معاملة سحابية ذرية.
- تركيز القائمة الافتراضية: حتى ١٦ إطاراً بعد `scrollToIndex`.
- المسجّل يُفتح بعد رفض الميكروفون: مقصود حتى تظهر اللوحة.
- عقد العزل/WIFE لم يُمسّ في دفعة الإغلاق ولم يُعاد تدقيقه سطراً سطراً هنا.
