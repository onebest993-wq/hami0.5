# قسم المهام — دفعة إكمال البقايا القابلة

**التاريخ:** ٣٠ آب ٢٠٢٦  
**النطاق:** أجندة المهام + ستارة الميدان + QuantumTasks. بلا إعادة تصميم، بلا فك عزل الشبكة، بلا إسقاط AES، بلا مزامنة تقويم لعناوين الميدان.

## ما أُنجز في هذه الدفعة

| العمل | الأثر |
|--------|--------|
| `useQuantumTasksBackgroundFlush` | تفريغ القرص فور `pagehide`، وبعد 900ms عند إخفاء التبويب، **وفوراً** عند `hami-native-app-state` غير النشط — Capacitor قد يجمّد JS قبل مؤقّت الإخفاء |
| إصلاح `useVisibilityAwareInterval` (من بداية الدفعة) | النبض عند العودة حتى لو المؤقّت ما زال مسجّلاً؛ ترحيل الأجندة + ساعة الستارة |
| `FieldTasksFatalDialog` مؤجَّل + تسخين بعد hydrate | حوار الحتمي خارج مقطع الستارة الأول، بدون انتظار أول تأكيد بعد التحميل |
| `inert` على طبقة الستارة أثناء الحوار الحتمي | لا نقر من خلف الحوار؛ `aria-modal` للستارة يُرفع أثناء الحوار |
| `FieldTasksSheetChrome` | رأس / فراغ / قائمة اليوم خارج ملف البوابة |
| `TasksManagerOverlays` + `TasksManagerFatalDialog` | حوارات الأجندة والمساعدة خارج الملف الأم؛ حوار الحتمي بنفس العلامات السابقة |
| قشرة الفتح الفوري (من بداية الدفعة) | ثوابت مشتركة بين React و`innerHTML` |
| إزالة `fatalPulse` + `TaskCardStatusRow` (من بداية الدفعة) | كود ميت + تقسيم بلا تغيير بصري مقصود |
| حراسة مصفوفات البطاقة/التوقيع | `expenses` / `subTasks` / `documentRequirements` لا تُسقِط الرسم إن وصلت ناقصة من التخزين |

## الاختبارات

Vitest لشرائح المهام + الترحيل + التوقيع + الستارة + العزل + كثافة/نظافة/أمان/موبايل + صدق العلل + تفريغ الخلفية + ثبات المزود: **ناجحة** (١١٨ في القياس الأخير لهذه الشرائح).

فشل `phase9ExecutionStorageStemCut` على `lawyer-cloud` / `vaultBlobPathLite` — **خارج قسم المهام** ولم يُمسّ في هذه الدفعة.

لم يُشغَّل Playwright ولا `tsc` كامل ولا جهاز ولا متصفح تفاعلي. الخادم `npm run dev` كان يعمل؛ التغييرات منطقية/تقسيم لا إعادة رسم مقصودة.

**جاهز للانتقال:** نعم لهذه الدفعة (ما كان قابلاً للإكمال دون إذن بصري أو كسر عقد).

## الحدود — ما لم يُغيَّر عمداً

- **شارة المصروف** تُعرض إن وُجدت في التخزين — بلا واجهة إضافة. إعادة الواجهة تحتاج إذناً صريحاً؛ إخفاء الشارة تغيير بصري.
- **تثبيت ستارة واحد / التثبيت عبر الأيام / `status: pending` بعد الإنجاز / النسخة الحية تربح عند الدمج:** عقد اختبار قائم لا علة.
- **قشرة الفتح الفوري:** نسختان تنفيذيتان (DOM فوري + React) بنفس الثوابت — متعمّد لمسار الطلاء قبل الـ chunk.
- لا مزامنة تقويم لعناوين مهام الميدان، لا فك AES عند الراحة.
- Playwright / جهاز / `tsc` كامل: غير منفَّذة — لا ادّعاء جاهزية أصل.
