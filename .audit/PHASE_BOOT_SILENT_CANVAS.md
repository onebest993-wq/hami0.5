# إغلاق — إقلاع صامت عالمي

تاريخ: 2026-08-11

## القرار

إقلاع **صامت**: سطح لوني `#0a0f1c` فقط — بلا كلمة، بلا شعار، بلا أنيميشن.

نفس لون بوابة الدخول واللوحة → الكشف غير محسوس لونياً (معيار تطبيقات عالمية).

## ما تغيّر

| سطح | التغيير |
|-----|---------|
| `index.html` | طبقة فارغة `data-hami-boot-mode="silent-canvas"` |
| `hami-home-static-shell.css` / `hami-boot-shell.css` | إزالة wordmark؛ خلفية فقط |
| Android `splash_screen.xml` | لون فقط |
| Android 12+ SplashScreen | أيقونة شفافة `splash_icon_blank` |
| e2e | يتحقق من غياب wordmark |
