# قسم الإعدادات — ظهور تلقائي / سلوك غريب

> **حالة الأرشيف:** بلاغ مستخدم: المركز يظهر أحياناً من تلقاء نفسه أو يتصرف بغرابة.  
> **سابق غير مُعاد:** كسل المنظر، حضور الطبقة، خروج CSS عبر الـ hub.  
> **عقد قائم:** بلا دمج الشجرتين، بلا تشديد `keepAlive`، بلا Playwright / جهاز.

**التاريخ:** ٣١ آب ٢٠٢٦  
**النطاق:** كشف الطبقة بلا لمسة، وإعادة الفتح أثناء تلاشي الإغلاق.

---

## السبب

1. تسخين `keepAlive` يركّب البوابة. إن علّق `React.lazy` يظهر `SettingsInstantPaintCover` فيطلي الطبقة كفتح حقيقي.
2. خروج الـ hub يزيل `data-hami-settings-open` فوراً بينما الطبقة `pointer-events: none`. اللوحة تُصبح قابلة للنقر تحت التلاشي (220ms) وكبح إعادة الفتح 90ms فقط — لمسة الترس تعيد الفتح.

---

## ما أُنجز

| العمل | الأثر |
|--------|--------|
| الغطاء لا يطلي إلا إن كانت الطبقة مكشوفة أصلاً | تسخين المنزل لا يفتح المركز |
| `paintSettingsInstantChrome` / `openSettings` / الترس يرفضون أثناء الكبح أو `closing` | لا إعادة فتح أثناء التلاشي |
| اللوحة `pointer-events: none` طوال `data-hami-settings-closing` | النقر لا يخترق إلى الترس |
| `adoptSettingsOverlayHostNode` ينشئ العقدة مغلقة | إنشاء DOM ≠ كشف |
