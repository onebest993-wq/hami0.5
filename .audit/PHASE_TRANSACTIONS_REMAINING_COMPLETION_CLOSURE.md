# قسم المعاملات — إكمال احترافي للبقايا القابلة

**التاريخ:** ٣١ آب ٢٠٢٦  
**النطاق:** بلاطة `hubTransaction` / مركز Threading. بلا إعادة تصميم، بلا فك AES.  
**لاحق:** مسار التقويم القديم (`TransactionDB` في تقليم/تعديل) أُغلق في `PHASE_CALENDAR_TRANSACTION_LEGACY_PATH_CLOSURE.md`.  
**سابق هذه الجلسة:** تسخين مفتاح الخيوط فقط + إعادة الربط بعد الفك + قراءة بلا `kickHydrate`.

---

## ما أُغلق في هذه الدفعة (كان معلناً حداً وهو قابل الآن)

| العمل | الأثر |
|--------|--------|
| دمج KV بـ `mergeTransactionsThreadingStates` | كان يختار الحالة الأحدث زمنياً كاملةً فيمسح معاملات محلية أمام سحابة أحدث فارغة |
| `emitTransactionsThreadingDump` بعد الدمج وبعد hydrate | القرص المحدَّث يصل للمخزن الحي **بعد الخمول** دون حبس أول إطار |
| `applyDump` على نفس نسخة المستودع | لا يُستبدل `Persistent` أثناء مؤقّت الحفظ فيُكتب dump قديم |
| نسخة احتياطية لمجال `transactionsThreading` | الحالة كائن؛ تُغلَّف `[state]` وتُستعاد بفك العنصر الأول — لا تُخلط مع كيس `v1` |
| `persistTransactionsSecure(..., { skipIfUnchanged: false })` | بعد `setItemSync` كانت الذاكرة تطابق فيُتخطى IndexedDB |
| خمول الفتح يستدعي `fetchTransactionsThreadingState` | يُشغِّل دمج KV في الخلفية بعد الطلاء |

---

## الاختبارات

Vitest شرائح هذه الدفعة + حراسة الصدق + العزل + الاستعادة: **ناجحة** (١٣ ملفاً / ٤٩ في القياس الموجّه، ثم ٨ ملفات انحدار / ٤١).

لم يُشغَّل: Playwright، جهاز Capacitor، `tsc` كامل، قياس TTFI حي.

## الحدود — حدود فعلية لا تأجيل

1. **`TransactionDB` / `hami:transactions:v1` كصنف تخزين:** لم يُحذف من وحدة السحابة (اختبارات عزل + استيرادات قائمة). مسار التقويم الحي لم يعد يقرأه — انظر تقرير التقويم.
2. **ضريبة حزم البناء المشتركة:** أول قسم في الجلسة يدفع أوراقاً من Rollup — ليست منطق المعاملات.
3. **تصميم بصري إضافي:** يحتاج إذناً صريحاً.
4. Playwright / جهاز / `tsc` كامل: غير منفَّذة.
