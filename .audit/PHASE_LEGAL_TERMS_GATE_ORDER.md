# LEGAL TERMS GATE ORDER — 2026-08-29

## القرار المعتمد

الترتيب الأصح لمنتج قانوني (وليست بطاقة «عرض» وسطية قبل أي شيء):

1. **بطاقة الاختيار أولاً** (دخول / إنشاء حساب / ضيف)
2. عند اختيار مسار بلا قبول سابق → **الوثيقة كاملة مباشرة** (بدون زر «عرض»)
3. بعد «أوافق» → متابعة المسار المختار
4. جلسة قائمة بلا قبول → الوثيقة كاملة قبل اللوحة (امتثال)

لماذا أفضل من الحائط القديم؟ نية المستخدم واضحة، موافقة مستنيرة على نص كامل، وأقل احتكاك قبل القرار.

## ما تغيّر

- `LegalTermsConsentGate`: إزالة المسار المضغوط وزر «عرض» — التحميل يفتح نص الوثيقة فوراً
- `LawyerAuthGate`: `requireTermsThen` عند التسجيل/الدخول/الضيف
- `useLawyerDashboardAuth`: لا شروط قبل الاختيار عند غياب الجلسة؛ الشروط تبقى إن وُجدت جلسة بلا قبول

## اختبارات

`LegalTermsConsentGate` + `LawyerAuthGate.contract` + `useLawyerDashboardAuth.termsGate` + `legalTermsAcceptance` — نجحت.
