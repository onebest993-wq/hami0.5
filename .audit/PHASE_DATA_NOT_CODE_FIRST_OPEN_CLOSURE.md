# البيانات ليست الشيفرة — إغلاق صادق

**التاريخ:** ٣٠ آب ٢٠٢٦  
**النطاق:** السبب الرابع فقط — التشفير المحلي، الفهرسة، الشبكة، السحابة، منشورات المنتدى بعد رسم الهيكل.  
**سابق:** تقسيم الكود، حجم المنتج، تكلفة التحليل.  
**ليس نطاقاً:** دمج الأقسام في الإقلاع، فك كل الأضابير عند المنزل، تغيير InstantPaint.

## القرار

الكِسرة الجاهزة لا تعني بيانات حية. الهيكل (InstantPaint / Host) يُرسم من الشيفرة؛ المحتوى يحتاج peek محلي أو فك مفتاح أو شبكة. لا نفحص كل المخزن عند الإقلاع. نبدأ **طبقة بيانات آخر قسم** مع كِسرته، والشبكة للمنشورات **مع** تحليل المنتدى لا بعده.

## ما أُنجز

- `sectionChunkDataWarm.ts`: مسار بيانات لكل قسم — peek/فهرس/قرص؛ شبكة فقط إن سمحت السياسة.
- `warmLastOpenedSectionChunk`: يطلق البيانات مع الكِسرة ولا ينتظر التحليل قبل بدء الجلب.
- `hydrateCommunityShellForInstantOpen`: `warmForumPostsCache` يبدأ قبل/مع `hydrateCommunityScreen` لا بعده.
- تنفيذ: فهرس المخزن + تسخين ملفات التنفيذ عند وجود userId — بلا بلوب إضبارة.
- منتدى: لقطة CommunityDB المحلية حتى بلا شبكة.
- دعاوى: `startLawsuitFilesEagerHydrate` فقط لا مسار الجزائي.
- معاملات: قراءة القرص لا سلسلة الفتح.

## الحدود

- بيانات السحابة تحتاج شبكة بعد الهيكل — لا تُختلق.
- فهرس البحث الكامل ما زال يُكمَّل داخل الموفر عند الحاجة.
- تأخير تسخين الطبقة الداخلية ٢٫٥–٨ ث أُلغي (خمول فقط).
