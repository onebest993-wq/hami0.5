# إغلاق جزئي — إقلاع تسلسلي صادق (2026-08-13)

## ما أُنجز
- علامة `first-tab` / `interactive` لم تعد من الجذع (`StemInstantBridge` / تقييم `LawyerDashboard`).
- تُعلَّمان بعد commit Minimal للمنزل الفعلي.
- FullBoot يُركَّب بعد `first-tab` الصادق؛ لا بوابة دخول مزدوجة أثناء التراكب.
- `getSession() === null` لا يمسح جلسة persist — المسح عند `SIGNED_OUT` فقط.
- مزامنة التوثيق خرجت من Inner → idle داخل BackgroundServices.
- تسخين JS للمنتدى بعد reveal + idle + حساب معتمد فقط.
- تسخين FullBoot/MainView بعد first-tab لا أثناء أول طلاء Minimal.
