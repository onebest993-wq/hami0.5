# قسم المستودع — دفعة إكمال البقايا القابلة

> **حالة الأرشيف:** موجة إكمال بقايا. إغلاق القسم الجامع: `.audit/PHASE_REPOSITORY_SECTION_CLOSURE.md`.

**التاريخ:** ٣٠ آب ٢٠٢٦  
**النطاق:** المستودع الذكي فقط. بلا إعادة تصميم، بلا فك WIFE/الشبكة/ختم KV، بلا منتدى `LegalRepository`، بلا أجندة المهام.

**سابق غير مُعاد:** تنحيف بصري، نظافة موجة 2، علل خفية (تقرير مستقل). هذه دفعة إكمال لما أُعلن حداً وكان قابلاً للتنفيذ الآن، مع علل ظهرت أثناء المسح.

---

## ما أُنجز في هذه الدفعة

| العمل | الأثر |
|--------|--------|
| تراجع إلحاق الإضبارة | إن فشل إخفاء المسودة أو `bindToDossier` تُحذف الملاحظة المضافة بالمعرّف — لا تبقى نسخة يتيمة في الملف |
| `append*` يعيد `{ file, noteId }` | التراجع دقيق وليس استعادة لقطة كاملة قد تمسح تعديلاً معاصراً |
| `stripRepositoryHtml` في حمولة الإضبارة | نفس سلوك التعرية بلا regex مكرّر |
| حذف غرفة: جلسة إلزامية إن وُجدت وثائق | بلا جلسة كانت الغرفة تُحذف وتبقى الوثائق بـ `roomId` ميت فتختفي من العام والغرفة |
| حذف غرفة: استعادة النقل + حراسة تداخل | إن فشل الوسط تُعاد `roomId` للملاحظات/الوثائق التي نُقلت؛ لا حذف مزدوج |
| Escape أثناء حفظ المسودة أو رفع المرفق | كان يسقط المسودة أو يغلق المستودع فوق حفظ جارٍ |
| إلغاء المسودة لا يعمل أثناء `saving` | نفس الحراسة من الزر لا من Escape فقط |
| `data-note-id` على بطاقات المخزن والإضبارة | تركيز البحث/التنبيه يجد البطاقة لا الملاحظات العامة فقط |
| توقيع القائمة التدريجية = طول + هاش كل المفاتيح | تبديل بطاقة وسطى كان يُبقى نفس التوقيع (أول/آخر فقط) |
| كاش الخلاصة يشمل `lawyerNote` | تعديل ملاحظة المحامي بلا `updatedAt` كان يُبقي كاشاً stale للبحث |
| حذف/حفظ ملاحظة إضبارة مع توست فشل | صمت سابق عند ملف/معرّف مفقود |

## ما رُاجع ولم يُغيَّر (عقد أو حد تقني)

- قائمتا الخلاصة وشريطا المحرّر — حيّان، بلا إذن بصري للدمج.
- المسجّل يُفتح بعد رفض الميكروفون — مقصود.
- احتياطي الأداء 1.2 ث وزر الإغلاق المزدوج — عقد اختبار.
- PDF / WIFE / keepAlive / عزل الشبكة.
- تراجع الربط بعد نجاح `bind` وفشل `refreshDocs` فقط: البيانات محفوظة؛ التحديث أفضل جهد.
- استعادة حذف الغرفة أفضل جهد إن فشل `onSaveNote` أثناء التراجع نفسه.

- لا تغيير بصري مقصود.
