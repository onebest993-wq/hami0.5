# قسم الإعدادات — إغلاق الحدود الثلاثة (مساران، بصمة، تحقق)

> **حالة الأرشيف:** المالك طلب التعامل باحترافية مع ما وُصف حدّاً لا تأجيلاً.  
> **سابق غير مُعاد:** ضغط الجذع، حذف الصفوف، عزل شبكة، ختم سحابة، تبويبات القشرة.  
> **عقد قائم:** بلا `useLawyerSettingsCloudSync`، بلا تقويم/مهام من الإعدادات، بلا دمج شجرة React داخل HTML (hydration).

**التاريخ:** ٣٠ آب ٢٠٢٦  
**النطاق:** توحيد عقدة الطبقة، سقف تلميح البصمة، مصدر أيقونات واحد.  
**خارج النطاق:** Playwright / جهاز / `tsc --noEmit` صفري للمستودع.

---

## صدق عن الحدود

| الحد | الحكم بعد هذه الدفعة |
|------|------------------------|
| مساران قشرة ثم React | **لم تُدمَج الشجرتان.** توحّدت **العقدة**: القشرة ابنة `[data-testid=hami-settings-overlay-host]` وHost يتبناها كحاوية portal. الإزالة عند `data-settings-root` / `hami-settings-shell` |
| Playwright / جهاز | **لا يُشغَّل** — عقد الجلسة |
| `tsc --noEmit` صفري | غير متحقق للمستودع. العقد: `guard:tsc` مِسنَنة، بلا `--save` |
| تلميح البصمة الأصلي الطويل | **أُغلق تخطيطاً:** `line-clamp-2` + `max-h-[2.25rem]`. النص الكامل في `title` |

---

## ما أُنجز

| العمل | المصلحة |
|--------|---------|
| `adoptSettingsOverlayHostNode` — طبقة واحدة z-200 | لم تعد قشرة z-199 خلف Host فارغ z-200 |
| القشرة `position:absolute` داخل الطبقة | لا تحويل متداخل مع حركة الدخول |
| Host: `createPortal(HamiSettings, host)` | نفس العقدة من الطلاء حتى الالتزام |
| `dismiss` و`beginSettingsShellExit` ينتظران شجرة React | قشرة بلا shell لا تُحسب Hostاً حيّاً ولا تؤخّر الإغلاق 220ms |
| `settingsNavIconInner.ts` | مسار SVG واحد للقشرة والهيدر |
| صف البصمة: `min-h` + `max-h` + `line-clamp-2` + `title` | لا قفزة بعد المسبار ولا تمديد بسطر ثالث |
