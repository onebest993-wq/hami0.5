### 2️⃣ الفصل المالي الدقيق (Financial Isolation)

#### أ) البنية الجديدة للأتعاب

```javascript
// الأتعاب المحكوم بها (يدفعها المدين)
lawyerFeesAmount: 150000
↓
الإدارة المركزية → Tab 3 → قسم "يتحملها المدين"
↓
يُضاف إلى totalOwed

// الأتعاب المتفق عليها (يدفعها الموكل)
clientFeesAmount: 500000
↓
قسم منفصل: "💼 حسابات الموكل الخاصة"
↓
لا يُضاف إلى totalOwed
```

#### ب) التعديلات في الملفات

**ExecutionDashboard.tsx**:
```javascript
// السطر ~119: Data extraction
lawyerFeesAmount = 0  // Court-ordered (المحكوم بها)
clientFeesAmount = 0  // Private client (المتفق عليها)

// السطر ~175: Total calculation
totalOwed = debtAmount + courtFees + directorateFees + lawyerFeesAmount
// ملاحظة: clientFeesAmount غير مضمن
```

**FinancialOperationsCenter.tsx**:
```javascript
// السطر ~473: قسم يتحملها المدين
{executionFee > 0 && (
  <div>أتعاب محاماة محكوم بها: {executionFee}</div>
)}

// السطر ~542: قسم حسابات الموكل الخاصة
{clientFees > 0 && (
  <div className="indigo/purple gradient">
    💼 حسابات الموكل الخاصة
  </div>
)}
```

### 3️⃣ إحياء أسلحة التنفيذ (Coercive Arsenal Revival)

- **بعد**: Grid كامل بجميع الأدوات

#### ب) الحالات الثلاث للأدوات

**1. مقفلة (Grace Period Active):**
```css
opacity: 50%
cursor: not-allowed
Lock icon في الزاوية
```

**2. مفتوحة (Grace Period Ended):**
```css
opacity: 100%
cursor: pointer
hover effects active
```

**3. استثناء النفقة (Alimony Override):**
```javascript
// طلب الحبس يُفتح فوراً في قضايا النفقة
disabled={!gracePeriodEnded && !isAlimonyClaim}
```

- **الملف**: `ExecutionDashboard.tsx` (السطر ~2250)
- **التصميم**: Amber gradient مع AlertCircle
- **النص**: توضيح قانوني لسبب القفل ومتى سيُفتح
