## Imprisonment Eligibility Engine - Iraqi Execution Law

---

## 📋 نظرة عامة (Overview)

تم تطوير **محرك ذكي متكامل** لحساب أهلية طلب الحبس في إجراءات التنفيذ العراقية بناءً على:
- **قانون التنفيذ العراقي رقم 45 لسنة 1980**
- **المادة 112** (قيود العمر)
- **المادة 264** (حماية الأقارب)
- **قانون حماية الموظفين الحكوميين**

## 🎯 الوظائف الرئيسية (Core Features)

### 1️⃣ **حساب تلقائي فوري (Real-Time Calculation)**
- يعمل بنظام `useMemo` لإعادة الحساب عند تغيير أي من:
  - عمر المدين
  - مهنة المدين
  - صلة القرابة
  - نوع الدعوى
  - مبلغ الدين

### 2️⃣ **أربع قواعد قانونية صارمة (4 Legal Rules)**

#### ✅ القاعدة 1: قيد العمر (Age Constraint)
```typescript
// المادة 112 من قانون التنفيذ
if (debtorAge < 18) {
    blocked = true;
    reason = "المدين قاصر - لا يجوز الحبس قانوناً";
}

if (debtorAge > 60) {
    blocked = true;
    reason = "المدين متجاوز الـ60 عاماً - محمي من الحبس";
}
```

**الحالات:**
| العمر | الحكم |
|-------|-------|
| < 18 سنة | ❌ لا يجوز الحبس (قاصر) |
| 18-60 سنة | ✅ يجوز الحبس |
| > 60 سنة | ❌ لا يجوز الحبس (كبار السن) |

---

#### ✅ القاعدة 2: قيد المهنة (Profession Constraint)
```typescript
if (debtorProfession === 'موظف') {
    blocked = true;
    reason = "المدين موظف حكومي - محمي من الحبس";
}
```

**الحالات:**
| المهنة | الحكم |
|--------|-------|
| موظف | ❌ لا يجوز الحبس (حماية الموظفين) |
| كاسب | ✅ يجوز الحبس |

---

#### ✅ القاعدة 3: قيد القرابة (Kinship Constraint) **مع استثناء النفقة**
```typescript
// المادة 264: لا يجوز حبس الأقارب إلا في النفقة
if (kinship && claimType !== 'نفقة') {
    blocked = true;
}

// الاستثناء: قضايا النفقة تجيز الحبس حتى للأقارب
if (claimType === 'نفقة') {
    blocked = false; // السماح بالحبس!
}
```

**جدول القرابة:**
| صلة القرابة | الأمثلة | الحكم العام | استثناء النفقة |
|-------------|---------|------------|-----------------|
| أصل | أب، أم، جد، جدة | ❌ لا حبس | ✅ يجوز في النفقة |
| فرع | ابن، بنت، حفيد، حفيدة | ❌ لا حبس | ✅ يجوز في النفقة |
| زوج/زوجة | الزوج، الزوجة | ❌ لا حبس | ✅ يجوز في النفقة |
| لا قرابة | شخص غريب | ✅ يجوز الحبس | ✅ يجوز الحبس |

**مثال عملي:**
```
السيناريو 1:
- المدين: أب (أصل)
- نوع الدعوى: استحصال دين مالي
- النتيجة: ❌ لا يجوز الحبس

السيناريو 2:
- المدين: أب (أصل)
- نوع الدعوى: نفقة
- النتيجة: ✅ يجوز الحبس (استثناء!)
```

executionFee = debtAmount * 0.02; // رسوم التنفيذ 2%
