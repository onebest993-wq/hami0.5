## 🔧 التعديلات التقنية

### 1. إضافة `motion` من Framer Motion:
```jsx
import { motion } from 'motion/react';

<motion.div 
    initial={{ opacity: 0, y: 20 }}
    animate={{ opacity: 1, y: 0 }}
    transition={{ duration: 0.5 }}
>
```

### 2. إصلاح z-index:
- ✅ جميع العناصر التفاعلية لديها `relative z-10`
- ✅ Overlay: `absolute inset-0` (خلف المحتوى)
- ✅ النص والأيقونات: `relative z-10` (فوق الـ Overlay)

### 3. تحسين الأداء:
- ✅ `transition-all duration-300` (أسرع من 500ms)
- ✅ `ease-out` للحركات الطبيعية
- ✅ `will-change` ضمني عبر `transition-all`
