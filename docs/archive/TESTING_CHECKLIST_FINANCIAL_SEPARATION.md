# ✅ قائمة الاختبار: الفصل بين الدين والمصاريف

## 🎯 الهدف
التحقق من أن الملفات غير المالية **لا تعرض** قسم الدين، لكن **تعرض** المصاريف والأتعاب.

---

## 📋 سيناريوهات الاختبار

### ✅ سيناريو 1: ملف مالي (نفقة)

**الخطوات**:
1. افتح/إنشاء إضبارة تنفيذ نوعها: **نفقة**
2. اذهب إلى Dashboard

**النتيجة المتوقعة**:
```
✅ قسم "النفقة المحكوم بها" (أو "المبلغ المطلوب") → ظاهر
   ├─ المطلوب: XXX
   ├─ المسدد: XXX
   ├─ المتبقي: XXX
   └─ Progress Bar
   
✅ زر "تسجيل دفعة من المدين" → ظاهر

✅ قسم "أتعاب المحاماة (من الموكل)" → ظاهر
   ├─ المتفق عليه: XXX
   ├─ المستلم: XXX
   └─ المتبقي: XXX

✅ قسم "الرسوم والمصاريف القضائية" → ظاهر
   ├─ أتعاب الدعوى الأصلية: XXX
   └─ رسوم المديرية: XXX
```

**في Modal تسجيل الدفعة**:
```
✅ خيار "تسديد من دين الإضبارة الأصلي" → موجود
✅ خيار "تسديد أتعاب المحاماة المحكوم بها" → موجود
✅ خيار "تسديد رسوم المديرية" → موجود (للمدين)
✅ خيار "استلام الدفعة من الموكل الخاص" → موجود
```

```
✅ قسم "الرسوم والمصاريف القضائية" → ظاهر
```

**في Modal تسجيل الدفعة** (إذا كان موجود في مكان آخر):
```
❌ خيار "تسديد من دين الإضبارة الأصلي" → غير موجود
```

### ✅ سيناريو 3: ملف غير مالي (مطاوعة)

**الخطوات**:
1. افتح/إنشاء إضبارة تنفيذ نوعها: **مطاوعة**
2. اذهب إلى Dashboard

**النتيجة المتوقعة**:
```
❌ قسم "المبلغ المطلوب" → مخفي تماماً

✅ قسم "أتعاب المحاماة" → ظاهر
✅ قسم "الرسوم والمصاريف" → ظاهر
```

---

### ✅ سيناريو 4: نموذج الإنشاء - مالي

**الخطوات**:
1. اضغط "فتح إضبارة جديدة"
2. اختر نوع التنفيذ: **استحصال دين مالي**

**النتيجة المتوقعة**:
```
✅ قسم "الإعدادات المالية والأتعاب" → ظاهر
   └─ حقل "المبلغ المطلوب تنفيذه (دينار)" → ظاهر وقابل للتعديل
```

---

### ✅ سيناريو 5: نموذج الإنشاء - غير مالي

**الخطوات**:
1. اضغط "فتح إضبارة جديدة"
2. اختر نوع التنفيذ: **مطاوعة** (أو أي من القائمة غير المالية)

**النتيجة المتوقعة**:
```
❌ قسم "الإعدادات المالية والأتعاب" → مخفي تماماً
❌ حقل "المبلغ المطلوب تنفيذه" → غير موجود
```

---

### ✅ سيناريو 6: التبديل بين الأنواع (في نموذج الإنشاء)

**الخطوات**:
1. اضغط "فتح إضبارة جديدة"
2. اختر نوع: **استحصال دين مالي**
3. تحقق من ظهور حقل "المبلغ المطلوب"
4. غير النوع إلى: **مطاوعة**
5. تحقق من اختفاء الحقل

**النتيجة المتوقعة**:
```
Step 2-3: حقل "المبلغ المطلوب" → ظاهر ✅
Step 4-5: حقل "المبلغ المطلوب" → يختفي فوراً ❌
```

## 🔍 اختبارات الحافة (Edge Cases)

### ⚠️ Edge Case 1: تسليم ولد vs تسليم طفل

**التحقق**:
- كلاهما في القائمة غير المالية ✅
- كلاهما لا يظهر لهما قسم الدين ✅

### ⚠️ Edge Case 2: تخلية مأجور vs تخلية عقار

**التحقق**:
- كلاهما في القائمة غير المالية ✅
- رغم أن التخلية قد تتضمن متأخرات إيجار، لكن **التنفيذ هنا خاص بالإخلاء** وليس الدين
- قسم الدين مخفي ✅

### ⚠️ Edge Case 3: claimType غير محدد (undefined)

**السيناريو**: ملف قديم بدون claimType

**النتيجة المتوقعة**:
```typescript
// Logic: isFinancialClaim = !nonFinancialClaims.includes(undefined)
// Result: true (يعتبر مالي افتراضياً)
✅ قسم الدين → يظهر (fail-safe)
```

## 🐛 الأخطاء المحتملة (Bugs to Watch)

### ❌ Bug 1: قسم الدين يظهر للمطاوعة
**السبب**: claimType لا يطابق القائمة بالضبط (مسافة، همزة، إلخ)  
**الحل**: التأكد من التطابق الحرفي مع `ExecutionCreationView` options

### ❌ Bug 2: المصاريف مخفية للملفات غير المالية
**السبب**: شرط خاطئ تم تطبيقه على قسم B أو C  
**الحل**: التأكد من عدم وجود `{isFinancialClaim &&` قبل SECTION B/C

### ❌ Bug 3: خيار "تسديد الدين" موجود للمشاهدة
**السبب**: نسيان تطبيق الشرط على `<option value="debt">`  
**الحل**: تطبيق `{isFinancialClaim && <option...>}` ✅ (تم)

## ✅ قائمة التحقق السريعة

قبل الانتهاء، تحقق من:

- [ ] الملفات المالية (نفقة، دين) → قسم الدين **ظاهر**
- [ ] الملفات غير المالية (مشاهدة، مطاوعة) → قسم الدين **مخفي**
- [ ] **جميع** الملفات → أتعاب المحاماة **ظاهرة**
- [ ] **جميع** الملفات → الرسوم القضائية **ظاهرة**
- [ ] نموذج الإنشاء - مالي → حقل "المبلغ المطلوب" **موجود**
- [ ] نموذج الإنشاء - غير مالي → حقل "المبلغ المطلوب" **غير موجود**
- [ ] Modal تسجيل الدفعة - مالي → خيار "تسديد الدين" **موجود**
- [ ] Modal تسجيل الدفعة - غير مالي → خيار "تسديد الدين" **غير موجود**
- [ ] Auto-layout → الأقسام الظاهرة **تملأ الفراغ** بدون white space
