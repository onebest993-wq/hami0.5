# 🔥 دليل محرك النفقة الشرعية - Alimony Engine Guide

## نظرة عامة

تم تطوير **محرك النفقة الشرعية** كجزء متقدم من نظام "ملف الدعوى الذكي" للقانون العراقي، وهو مصمم خصيصاً لمعالجة الحالات القانونية المعقدة المتعلقة بالنفقة الشرعية وحصانة الموظفين.

## 📋 الميزات الرئيسية

### ✅ الأمر الأول: هندسة تصنيف الدين واختراق حصانة الموظف

**المشكلة القانونية:**
عند تنفيذ أحكام النفقة الشرعية على موظف حكومي، تواجه المحاكم تحدياً قانونياً فريداً: هل راتب الموظف يكفي لتسديد النفقة المطلوبة؟

**الحل الذكي:**
- تصنيف دقيق للدين (دين مالي اعتيادي / نفقة شرعية)
- إدخال راتب الموظف الصافي
- إدخال النفقة المستمرة (شهرياً) + القسط المتراكم
- **محرك رياضي** يقارن تلقائياً: هل (النفقة المستمرة + القسط المتراكم) > راتب الموظف؟

**النتيجة:**
- إذا كان الراتب **لا يكفي**:
  - 🚨 تحذير تلقائي: "الراتب لا يغطي كامل النفقة"
  - ⚖️ يصبح الموظف **ملزماً قانوناً** بتقديم كفيل ضامن
  - 🔓 فتح خيارات: "إضافة كفيل" أو "طلب حبس تنفيذي"

### ✅ الأمر الثاني: محرك الإنذار الاستراتيجي

**الخطأ القانوني الشائع:**
كثير من المحامين المبتدئين يطلبون حبس المدين على **كامل المبلغ المتراكم دفعة واحدة**، وهذا خطأ استراتيجي فادح!

**لماذا؟**
بعد انتهاء فترة الحبس، يُعتبر المدين قانوناً **"عاجزاً"** عن ذلك المبلغ، ولا يمكن حبسه عليه مجدداً. بمعنى آخر: **فقدان ورقة الضغط إلى الأبد!**

**الحل الذكي:**
- عند اختيار طريقة المطالبة: **دفعة واحدة** أو **تسوية وتقسيط**
- إذا اختار المحامي "دفعة واحدة":
  - 🛑 **تحذير أحمر ضخم نابض** بالخطر الاستراتيجي
  - شرح كامل للعواقب القانونية
  - توصية بـ **"التسوية والتقسيط"** + طلب كفيل ضامن

### ✅ الأمر الثالث: رادار التسديد والإخلال (Binary Action Bar)

**المشكلة:**
متابعة التزام المدين بالدفعات الشهرية معقدة وتحتاج لنظام سريع.

**الحل:**
زران ضخمان واضحان:
1. **✅ تم تسديد الدفعة الحالية** (أخضر)
2. **❌ المدين أخلّ بالدفع** (أحمر)

**عند الضغط على "أخلّ بالدفع":**
تظهر خيارات التنفيذ التلقائية حسب الحالة:

- **إذا كان هناك كفيل:**
  - 🚨 طلب إحضار المدين والكفيل جبراً

- **إذا لم يكن هناك كفيل + الدين نفقة:**
  - 🔒 إيقاع الحبس التنفيذي للامتناع عن تسديد النفقة

- **إذا كان موظف + الراتب لا يكفي + لا يوجد كفيل:**
  - 👮 تعميم أمر قبض لعدم كفاية الراتب وعدم وجود كفيل

## 🚀 كيفية الاستخدام

### الخطوة 1: فتح لوحة التنفيذ
1. من لوحة المحامي، انقر على إضبارة تنفيذية
2. ستفتح نافذة **ExecutionDashboard**

### الخطوة 2: الدخول إلى غرفة العمليات المالية
1. انقر على زر **"غرفة العمليات المالية"** (Master Financial Modal)
2. ستفتح نافذة كاملة الشاشة للإدارة المالية

### الخطوة 3: تفعيل محرك النفقة
في الجزء العلوي من النافذة، سترى:

#### 🧠 محرك تصنيف الدين (النفقة الشرعية)

**اختر التصنيف:**
- ◼️ دين مالي اعتيادي (عادي)
- ⬛ نفقة شرعية (يفتح المحرك)

**إذا اخترت "نفقة شرعية" + المدين "موظف":**
ستظهر حقول إضافية:
1. 💼 **مقدار الراتب الصافي للموظف**
   - مثال: `850,000` دينار

2. 📅 **النفقة المستمرة (شهرياً)**
   - مثال: `300,000` دينار

3. 📊 **القسط المتراكم**
   - مثال: `1,200,000` دينار

**المحرك الرياضي سيعمل تلقائياً:**
- المجموع المطلوب = 300,000 + 1,200,000 = **1,500,000** دينار
- الراتب الصافي = **850,000** دينار
- النتيجة: **الراتب لا يكفي!** ❌
- العجز = **650,000** دينار

**سيظهر تحذير أحمر:**
> ⚠️ **الراتب لا يغطي كامل النفقة**
> 
> الموظف ملزم قانوناً بتقديم (كفيل ضامن) للمبلغ المتبقي (650,000 د.ع) وإلا تعرض للحبس التنفيذي.

**خياران:**
- ✅ **إضافة كفيل ضامن** (يفتح نافذة الكفيل)
- 🔒 **طلب حبس تنفيذي** (يولد طلب تلقائي)

### الخطوة 4: اختيار طريقة المطالبة

**⚖️ طريقة المطالبة بالنفقة المتراكمة:**
1. 💥 **دفعة صفقة واحدة** (خطر!)
2. 🤝 **تسوية وتقسيط** (موصى به)

**إذا اخترت "دفعة واحدة":**
سيظهر تحذير استراتيجي ضخم:

> 🛑 **تحذير استراتيجي شديد**
> 
> المطالبة بالنفقة المتراكمة كدفعة واحدة وحبس المدين عليها يعني أنه بعد انتهاء مدة الحبس **سيُعتبر (عاجزاً قانوناً)** عن هذا المبلغ، **ولن تتمكن من حبسه عليه مجدداً!**
> 
> ✅ البديل الأفضل:
> يُنصح بشدة إبرام (تسوية وتقسيط) وطلب (كفيل ضامن) لضمان استمرار ورقة الضغط.

### الخطوة 5: استخدام رادار التسديد

**⚡ رادار التسديد والإخلال:**

كل شهر، اختر أحد الخيارين:
1. ✅ **تم تسديد الدفعة الحالية** → يسجل الدفعة ويحدث السجل
2. ❌ **المدين أخلّ بالدفع** → يفتح قائمة الإجراءات:

**إجراءات الإخلال:**
- إذا كان هناك كفيل: **طلب إحضار المدين والكفيل جبراً**
- إذا لم يكن كفيل: **طلب حبس تنفيذي**
- حالة خاصة (موظف + راتب غير كافٍ): **تعميم أمر قبض**

## 📊 الحسابات الرياضية

### محرك الحساب:
```javascript
const netSalary = parseFloat(employeeNetSalary.replace(/,/g, '')) || 0;
const continuous = parseFloat(continuousAlimony.replace(/,/g, '')) || 0;
const accumulated = parseFloat(accumulatedAlimony.replace(/,/g, '')) || 0;

const totalRequired = continuous + accumulated;
const salaryInsufficient = totalRequired > netSalary && netSalary > 0;
const deficit = totalRequired - netSalary;
```

### مثال:
- راتب الموظف: `850,000` دينار
- النفقة المستمرة: `300,000` دينار/شهر
- القسط المتراكم: `1,200,000` دينار

**الحساب:**
```
المطلوب = 300,000 + 1,200,000 = 1,500,000 دينار
الراتب = 850,000 دينار
العجز = 1,500,000 - 850,000 = 650,000 دينار ❌
```

**النتيجة:**
الراتب لا يكفي → يجب تقديم كفيل ضامن أو طلب حبس تنفيذي.

## ⚠️ ملاحظات مهمة

1. **لا يتم عرض محرك النفقة** إلا إذا كان نوع التنفيذ **"دين مالي"** (وليس تسليم أعيان أو التزام بعمل)

2. **حقول الموظف تظهر فقط** إذا كان تصنيف الدين = "نفقة شرعية" **و** وظيفة المدين = "موظف"

3. **التحذير الاستراتيجي** يظهر فقط للنفقة الشرعية وليس للديون العادية

4. **رادار التسديد** يعمل فقط عند وجود تسوية نشطة أو دين مصنف كـ "نفقة شرعية"
