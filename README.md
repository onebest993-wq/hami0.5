## 🔭 نظرة عامة

Hami Legal System هو نظام متكامل لإدارة القضايا القانونية، مع تركيز خاص على:
- إدارة القضايا الجزائية والمدنية
- تنفيذ الأحكام
- إدارة الوثائق والمستندات
- التزام بالقوانين العراقية
- الأمان العالي والخصوصية

## ✨ الميزات الرئيسية

### 📊 إدارة القضايا
- لوحة تحكم للمحامين
- إدارة القضايا الجزائية والمدنية
- تتبع مراحل القضايا
- تذكير بالمواعيد النهائية

### 🔒 الأمان والخصوصية
- **WIFE Protocol** - نظام أمان متقدم
- **E2EE** - تشفير طرفي لطرف للبيانات الحساسة
- **Biometric Auth** - المصادقة الحيوية (Android/iOS)
- **HttpOnly Sessions** - جلسات آمنة

### 📱 تطبيقات متعددة
- تطبيق ويب متجاوب
- تطبيق Android عبر Capacitor
- تطبيق iOS عبر Capacitor

### 📦 إدارة المستندات
- مخزن آمن للوثائق
- تتبع المستندات المرتبطة بالقضايا
- OCR للمستندات (اختياري)

### 👥 المجتمع القانوني
- منصة للتعاون بين المحامين
- مشاركة القضايا (بأذونات)
- منتدى للنقاشات القانونية

## 📦 المتطلبات

- **Node.js**: v20.x
- **npm**: v9 أو أحدث
- **Supabase**: لحساب cloud (اختياري للتطوير المحلي)
- **Upstash Redis**: للإنتاج (إلزامي)

## 🚀 التثبيت والتشغيل

### 1. استنساخ المستودع

```bash
git clone <repository-url>
cd "New folder"
```

### 2. تثبيت التبعيات

```bash
npm ci
```

### 3. إعداد المتغيرات البيئية

انسخ ملف المتغيرات البيئية:

```bash
cp .env.example .env
```

ثم عدّل الملف `.env` وأدخل قيمك (راجع [`.env.example`](.env.example) للحصول على الشرح الكامل).

### 4. تشغيل خادم التطوير

```bash
npm run dev
```

سيتم فتح التطبيق تلقائياً على: `http://localhost:8080`

## 📜 المهام المتاحة

| المهام | الوصف |
|--------|--------|
| `npm run dev` | تشغيل خادم التطوير |
| `npm run dev:fresh` | تشغيل خادم التطوير مع مسح الكاش |
| `npm run build` | بناء النسخة الإنتاجية |
| `npm run typecheck` | فحص أنواع TypeScript |
| `npm run test` | تشغيل الاختبارات (Vitest) |
| `npm run test:run` | تشغيل الاختبارات بدون واجهة |
| `npm run test:e2e` | تشغيل اختبارات E2E (Playwright) |
| `npm run test:security` | تشغيل اختبارات الأمان |
| `npm run health` | فحص صحة المشروع الكامل |
| `npm run build:vercel` | بناء للنشر على Vercel |
| `npm run cap:sync` | مزامنة Capacitor |

## 🛠️ التقنيات المستخدمة

### الواجهة الأمامية
- **React 18** - مكتبة واجهات المستخدم
- **TypeScript** - الأمان النوعي
- **Vite 7** - أداة بناء سريعة
- **Tailwind CSS v4** - إطار عمل CSS
- **Framer Motion** - حركات ورسوم متحركة
- **Zustand** - إدارة الحالة
- **Radix UI** - مكونات UI يمكن الوصول إليها

### الواجهة الخلفية
- **Supabase** - قاعدة بيانات PostgreSQL + Auth + Storage
- **Vercel Functions** - API Routes (Edge)
- **Upstash Redis** - مخزن مؤقت موزّع

### الجوال
- **Capacitor 6** - أطار عمل تطبيقات الجوال
- **@aparajita/capacitor-biometric-auth** - المصادقة الحيوية

### الاختبار
- **Vitest** - إطار عمل اختبارات
- **Playwright** - اختبارات E2E
- **Testing Library** - اختبارات React

## 🔐 الأمان

### WIFE Protocol
نظام أمان مخصص يحمي من:
- هجمات CSRF
- سرقة الرموز (Token Theft)
- الهجمات الموزّعة (Rate Limiting)
- إلخ

### التشفير
- E2EE للبيانات الحساسة
- HttpOnly, Secure Cookies
- تشفير التخزين المحلي (SecureStore)

### مراجعة الأمان
```bash
npm run test:security
npm run health:security
```
